# COGNITION-003 — When an old trace matters today (frozen before implementation)

2026-11-11. Research HOLD. Stacked on COGNITION-002 (MOTIF PR #297), and MEMENTO's already native-validated private Understory owner connector. Protocol recorded **before implementation or test results**.

## Precise question
Does proactively preserving **unresolved, source-attributable two-hop associations** allow an idle-time MOTIF contemplation process to resurface an old contact when an unrelated *new operational incident* appears, propose a safe discriminating test, and achieve a verified simulator outcome? Is there any advantage over strong conventional provenance-aware indexed retrieval with the **same** source access, storage, budgets, and verification?

**Cognitive interpretation:** an intentionally engineered analogy to involuntary association, NOT an unconscious LLM process or access to model chain-of-thought.

## Fixed author-generated simulator
- 2 prior-day contact observations on each of 2 alternative relation chains (4 old records): `cue -> intermediate mark -> candidate component`, each edge source-bound. These are *possible* relations, not verified causes. Same old source graph precedes the unknown next-day event. The system does not receive the true faulty component.
- On day 2, an urgent new incident supplies a **cue only**, not a question about past records. The system may react by resurfacing matching old paths, but must TEST candidate components via a separate source-of-truth owner simulator before any REPAIR. Each TEST/REPAIR is an individually verified owner transition; no direct untested fix is allowed.
- Test budget: at most 2 probes and at most 1 repair, one event per synthetic world. The only successful outcome is the owner independently confirming the repaired fault.
- Five prespecified regimes: `stable` (path 1 true); `drift_alternative` (path 2 true); `drift_unmodeled` (neither old path true); `echo_source` (path 1 appears twice but has one source origin, therefore not trustworthy, path 2 is true); `unrelated_trigger` (new cue has no old match; true fault remains unreachable). The two latter cases are safety/abstention controls, not guaranteed solvable jobs.
- Each world has at least six possible replacement components; the actual correct component is hidden from all policies and only queried by the independent simulator.
- All sources are **invented, public-safe fixtures** with explicit provenance and temporal coordinates, never any user's private MEMENTO content. No external/private data or LLM calls.

## Four frozen policies
1. `motif_resurface`: *before the new incident* compile typed weak two-hop possible actions during declared idle work, retaining the provenance roots and historical Understory association/activation contract. On new cue, resurface candidates, rank as hypothetical affordances with **actual native MOTIF-003**, test each via owner, repair only after a true test receipt. GHoT/visible/consent gate inherited from COGNITION-001; nonadmitted Understory activation is carried as explicit packet/receipt, not canon.
2. `classical_cached`: strong matched classical source-aware two-hop index built during the same idle window, identical data, memory, preprocessing and probe budgets; on trigger, test the same eligible path order. It may tie exactly.
3. `classical_online_bfs`: strong conventional graph traversal with all the same old contacts and source roots, but builds candidate reachability when incident appears, measuring additional *trigger-time* graph work. Equal total compute permission and probe/action budgets; no artificial CPU cap applied to impair it. It may tie on verified outcomes.
4. `recent_only`: diagnostic ablation receiving only the new incident and no prior archive. Not a competitive baseline; may abstain or fail.

Source-aware rules shared by **all** informed arms: 2 independent origin roots required per cue-to-component chain; duplicate-origin echo is not independent. Two candidate paths allowed, ordered by historical slot/priority before knowing world outcome; test each sequentially until owner confirms target or budget ends. No report can directly justify a repair. If no matching source path, HOLD. Prior graph resemblance is PENCIL not truth. The native Free Graph validator is mandatory for every case; packet's task-world cut remains `unresolved` and no `constitutes`, `descends-from` or `owner-local` edges are emitted.

## Evaluation and heldout
Development seeds `(71001, 71011, 71021, 71031)`. **Fresh fixed heldout seeds `98201+43*i` for i=0..31**, 32 seeds per 5 regimes × 4 controllers = **640 measured runs**; separate 80 development runs. Seed algorithm deterministic SHA-256; these are one-author simulator tasks and NOT independent/real-world blind cases. Frozen before outcomes or code.
Primary: independently verified fixed-fault repair success, normalized success out of 160 cases per policy; also false repairs, correctly abstained unrelated triggers, and correctness of source-echo exclusions. Secondary: owner TESTs, repairs, explicit Understory activations, Free Graph native validation, archived evidence revisit counts, idle-index operations, on-event graph operations, total operations. A computational precompile advantage must be shown against `classical_cached`, not only against `classical_online_bfs`; operation counts are proxies, not measured latency, energy or human cognition. Report failure/negative results, no post-test method tuning. Preserve all owner receipts.
Falsifiers: spoofed or duplicate source roots must not constitute independent evidence; no solver may observe owner hidden fault before tests; wrong test never gives repair; drift cannot secretly rewrite old records; source packet tampering invalidates; app invisible/opt-out => no autonomous contemplation; public missing MEMENTO never represented as validated; hypothesized graph association cannot constitute a fact; no arbitrary external action.
