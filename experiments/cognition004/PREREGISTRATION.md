# COGNITION-004 — Unwritten Analogy: structural relations across alien domains

**Predeclared before implementation, 2026-11-11.** Research draft. Source stack: COGNITION-001/002/003. No production deployment, no historical private data.

## Question
Given previous verified task outcomes in unrelated domains whose **entity names share no tokens** with a new task, can MOTIF notice an **unwritten structural analogy**, propose an appropriate intervention, then verify it against an independent problem owner? Does a multi-perspective contemplative procedure actually outperform strong *conventional structural graph edit-distance retrieval* with identical source data, budget and evidence?

This is an engineered analogy experiment. Synthetic relations use a common typed, domain-neutral vocabulary (feed, delay, loop, signal, etc.). Thus structure is supplied through the ontology. It is NOT evidence that MOTIF inferred new ontology or discovered an unexpected real-world causal law.

## Frozen environment
- Source day: 5 programmer-authored small directed, edge-typed mechanism examples (feedback amplification, bottleneck, stale decision, synchronization, contention), each accompanied by a verified successful intervention and TWO independently labeled synthetic witness roots. Historical source nodes have a distinct domain-specific vocabulary (irrigation, music, event planning, networking, workshop). No historical source/target identity joins, co-occurrence links or pre-declared analogy.
- Encounter day: one unprompted new-domain incident in a sixth domain using **completely different node names**. The incident provides a directed typed graph of observable relations but never the true effective intervention. A separate simulator owner determines correctness and may authorize up to two diagnostic TEST actions and one REPAIR only after an owner-positive TEST. Historical facts are never rewritten. A source-root echo cannot masquerade as two independent witnesses.
- Regimes: `isomorphic` (exact analogue); `renamed_permuted` (disjoint nouns and shuffled node positions); `partial_observation` (one source edge hidden, candidate still eligible at edit distance <=1); `false_friend` (topology resembles prior case but critical causal relation changed, true fix OUTSIDE archive; no invented success); `echo_source` (correct source case's 2 supposed witnesses share an origin root; reject that case); `unfamiliar_structure` (new incident has no valid source precedent; refuse unverified action).
- Action choices: 5 source-verified interventions; 1 additional unobserved alternative known only to owner. Same task truth for all policies, no shortcut to read owner private hidden solution.
- Fair matched controls: `motif_council` (same relational edit-distance retrieval as conventional control, then source-witnessed analogical question via native MOTIF-003, native Free Graph unresolved projection, five programmed perspectives, owner-tested intervention); `classical_graph_edit` (**strong control**, same typed relation data, identical candidate ranking, same memoization/index and test budget, allowed to tie); `classical_exact_iso` (more restricted classical diagnostic, not primary comparator); `lexical` (weaker text-token baseline that cannot match disjoint domain names; labeled ablation, not representative of classical reasoning).
- Structural similarity computed under all node-bijections with a transparent edit count on directed typed edges, NOT LLM calls. A candidate with edit distance >1 must be excluded. Proposals are sorted by (edit distance, prior source index), before the owner truth is observed; compare source-root independence.
- Up to 2 TESTs + 1 REPAIR, with independently sealed owner receipts. No source nor graph link can imply an unverified repair. `MOTIF-003` is genuinely executed on hypothetical tests, but it is NOT allowed hidden oracle information or extra action budget.
- Native Free Graph `fg_core` validates an unresolved `connects` packet representing new proposed source→target analogy; no `constitutes`, `descends-from`, owner-local authority, or hidden target action in packet.
- Native private MEMENTO Understory may validate a four-record *invented* synthetic historical envelope (two contacts, one unresolved association, one new activation) through the previously connected owner-only bridge. Without authorized native MEMENTO checkout **HOLD**, not fake validation. Never export MEMENTO private source into public MOTIF.
- GHoT native policy, user opted-in and visible, favourable idle resources gate **preparation**; when idle not permitted, task-directed conventional online relation search can still run, but never pretend idle contemplation occurred. No always-on OS service.
- Historical analogy proposal statuses PENCIL/UNRESOLVED. The original sources are evidence of their own source-world outcomes, not universal evidence of successful target actions.

## Frozen test cohort and metrics
- Development seeds: 72001, 72011, 72021, 72031.
- Heldout seeds: `99101 + 47*i` for `i=0..31`: 32 fixed fresh author seeds × 6 regimes × 4 policies = **768 scored cases**, plus 96 development. No blind independent evaluation claimed.
- Primary: verified target repair (binary), false/unsafe repair count, unresolvable abstention. Paired MOTIF minus strong edit-distance classical success and owner TEST cost, separately by regime. No success claims based on proposal novelty alone.
- Secondary: # cross-domain analogies suggested, # structurally verified matches, owner TEST count, source-root exclusions, Free Graph real validator status, native MOTIF-003 invoked, Understory activation validated privately/explicit HOLD publicly, trigger-time/idle structural comparison counts, # unrelated node-name tokens (must be zero).
- Falsifiers: if owner gives no positive TEST, no REPAIR; source echo cannot count as independence; direction and edge type affect structural distance; a relation-name mismatch invalidates an alleged exact mapping; packet tamper fails native Free Graph check; private Understory cannot be silently treated as validated; app visibility/consent gates contemplation; no confidence/authority promoted because similarity exists; all matched policies have same actual owner and budgets; no hidden test-seed method tuning.
- Commit freeze before source code, then execute all methods and preserve negative results. Report that a tie vs exact edit-distance means only an integrated mechanism, not a novel algorithm.
