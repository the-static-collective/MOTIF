# COGNITION-004 — The Unwritten Relation

**Draft research experiment, not a deployed cognitive service.** The proposal came from MOTIF's COGNITION-003 limit: yesterday's links already named the cue. Can an old solved problem in another domain help with a new emergency **without sharing any object names** or possessing a recorded cross-domain link?

## Experiment in plain language
MOTIF previously encountered five successful problem resolutions: a repeating irrigation feedback fault, a throughput bottleneck in music production, stale measurements in volunteer coordination, timing synchronization in networking, and resource contention in a workshop. Their historical evidence belongs to five different synthetic roots and days.

A new incident in a fictional harbor presents an observed *directed, edge-typed relationship pattern* but **none of the nouns or entity names** of the five historical experiences. A new analogy must be derived from the structural relations, never simply retrieved through a pre-existing source/target edge. All five historical interventions are hypotheses until a distinct synthetic problem owner performs an actual diagnostic TEST in the new world. There is never an unverified REPAIR.

The underlying ontology (delay, feed, loop, etc.) is **provided by the programmer**. This is structural analogy under a shared representation, not discovery of a new ontology from raw language.

Six regimes:
- Exact cross-domain isomorphism.
- Identical typed relationships, randomized node ordering and unrelated nouns.
- One unobserved relationship: approximate analogy can propose a test but not claim truth.
- False friend: one missing critical relationship makes the old strategy wrong; only owner TEST can reject it.
- Echo source: two supposed corroborating historical witnesses share one origin and cannot license an intervention candidate.
- Completely unfamiliar causal structure: abstention is correct when no existing relation fits.

## Methods and strong control
- **MOTIF contemplation:** native GHoT resource policy gates historical preparation; true MOTIF-003 analyzes the possible TEST affordances. Real Free Graph packet IDs, validation and neighborhood traversal produce nonconstituting structural proposal links, never factual truth or owner authority. A private native MEMENTO Understory companion can validate two synthetic contacts, an unresolved association and a later activation.
- **Strong classical graph edit:** same five historical structures, actual structural matcher examining **all 120 node bijections** for each source, same edit threshold, source roots, idle preparation, permitted tests and verification. This is the **primary comparator** and may exactly tie.
- **Classical exact isomorphism:** deliberately weaker under incomplete observations, not the strongest structural method.
- **Lexical keyword:** deliberately weak diagnostic, with zero overlapping nouns and therefore no retrieval; not a general classical reasoning baseline.

Maximum two owner diagnostic TESTs and at most one REPAIR *after* a positive receipt. Every result is independently checked by the **separate programmed synthetic owner**, not an external real-world authority. Owner truth is never read in the policy. The source/current world relationship is not preencoded in Free Graph.

## Reproduce

```bash
python -m unittest discover -s experiments/cognition004 -p 'test_*.py' -v
python experiments/cognition004/analogy.py --split development > cognition004-dev.json
python experiments/cognition004/analogy.py --split heldout --full > cognition004-heldout.json
```

This needs pinned GHoT and Free Graph checkouts under `sources/ghot` and `sources/free-graph`, as supplied by GitHub Actions. The allowed private-source diagnostic, from a separately authorized local MEMENTO clone, is:

```bash
python experiments/cognition004/analogy.py --one-seed 72001 --regime renamed_permuted --memento-root /authorized/MEMENTO
```

The author-selected heldout seeds are `99101+47*i`, `i=0..31`: **768 cases** across six regimes and four methods; no independent blind benchmark claim. Compare verified interventions, false repairs, actual TEST costs and source-confirmed analogy validity, not merely number of interesting proposed cross-domain connections.

The first likely benefit is that structurally related tasks can share **possible** intervention tests across unrelated vocabularies. Whether this is more capable than conventional graph analogy is exactly what the strong comparator checks; a tie should be reported as such.
