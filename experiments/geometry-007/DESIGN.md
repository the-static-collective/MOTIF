# MOTIF GEOM-007 — Contextual Imagination / The Relational Imagination

**Status:** executable bounded **synthetic** experiment on a separate review branch. Built on GEOM-006's unmerged temporal Staircase Lab branch. Neither code nor confidence is automatically inherited into `main`, THOUGHT-006, 3rdi, ALEX, Free Graph or JAR;VIS. Python 3.10+ standard library only.

## The hypothesis and its falsifier

Can MOTIF represent several *locally coherent* interpretations of the same attributed problem, notice when they cannot be assembled into a single global description, and identify when its chosen representation hides the distinction needed to discriminate between surviving models?

Classical control: finite constraint satisfaction / relational join and categorical information gain. This experiment does **not** discover sheaf theory, prove geometric cognition, authenticate testimony, or create a true-world oracle. An observer's representation may obscure differences even when the typed underlying candidate assignments retain them; no proof that a spatial layout improves thinking is claimed.

## Local and global models

Each `Context` contains:

- a stable context ID, a declared source-root label, and a required **scope**;
- 1..13 categorical variables;
- a finite set of complete local assignments (alternative possibilities, not facts).

All contexts being glued must share the **exact same observer/time/decoder scope** string. The scope is unverified metadata, but differing scopes fail closed. This prevents silently identifying different observers, historic cuts or decoding constitutions. The local-to-global join enumerates complete compatible assignments while preserving each context's declared provenance. It is a finite classical CSP, not an implementation of general sheaf cohomology.

Three outcomes:

1. `INCOMPATIBLE_LOCAL_CONTEXTS`: no compatible global assignment. Return a subset-minimal conflicting context set with source labels. It is a contradiction **under the proposed grammar**, not a proven real-world contradiction. Pairwise-compatible but globally-incompatible 3-context controls are included.
2. `UNIQUE_WITHIN_GRAMMAR`: exactly one compatible assignment. This does not mean *true*, *proven* or *authorized*.
3. `PLURAL_WORLD_MODELS`: several candidate worlds survive. Do not select one arbitrarily.

Combinatorial bounds refuse before silently truncating possible worlds: at most 9 contexts, 13 variables, 4096 raw combinations and 512 compatible sections.

## Multiple views and a testable representation blind spot

A `Lens` is a view exposing specified variables and optional NONE/HEX/RADIAL **display**. None of these creates variables, sources, truth or actions. Two lenses can expose different projections of the same candidate worlds; their local coherence does not imply a unique global interpretation.

`representation_blind` is true exactly when multiple global models exist but the chosen view set maps them to the **same visible signature**. `hidden_discriminators` lists omitted variables on which the candidates actually differ. This is a conditional **representation-gap certificate**: under this synthetic model, the current chosen lens loses information that would help distinguish candidates. It does not prove a human/AI psychological blindness or that the variable is observable in reality.

A proposed second lens can expose a missing variable for further reasoning, but **reframing itself supplies no measurement**. Optional coordinates are display-only. A `NONE` lens and a geometry-on/off ablation must preserve the same semantic results.

## Choosing a new observation, not imagining an answer

A `Question` has a declared variable, finite positive cost, and explicit synthetic `permitted` flag. The selector requires a permitted, affordable, actually discriminating question, using **classical Shannon information gain under uniform candidate-world weights** divided by cost. This is an open-world planning proposal only; it never executes a probe, or invents a measured value. The sensor may ask about a hidden variable but not assume its outcome.

The `filter_on_observation` method is strictly a **PENCIL counterfactual**, labeled by an unverified source root, and cannot alter the original atlas.

## Demonstration

An observer has a stable outward route report. Two equally compatible hidden formation histories — primary independent source versus reposted echo — imply different reachable conclusions. The current `appearance` lens sees exactly the same route and knowledge status in both candidate worlds. `causal` includes the hidden lineage dimension, and a permitted source-origin question can separate the worlds at a synthetic cost.

A deliberately cheaper `forbidden-cheap` probe is refused. A route-status question is uninformative because both candidates predict the same value. Selecting the proposed source-origin question does not update any belief without a distinct observation.

```sh
cd experiments/geometry-007

python3 demo.py
python3 interface.py example-input.json

```

The suite includes randomized *independent exhaustive Cartesian-product* checks of the join, independent entropy calculations, unsatisfiable minimal cores, triple-wise contextual conflicts, off-scope rejection, input permission fences, malicious field refusal, no-map invariance, import-as-pencil from existing GEOM-006 categorical models, and combinatorial-abstention tests.

`benchmark.py` compares 100 fixed-seed developer cases against a direct classical partition baseline **with the same candidate worlds and cost/permission declarations**. It is not frozen independent evaluation. Parity, not superhuman advantage, is the expected result. See `benchmark-results.json` for the actual run.

## Foreign mathematical ancestry and limits

The algorithms here are elementary CSP / relational joins, discrete local-to-global compatibility questions inspired by contextuality and sheaf-theoretic language, and classical information theory. A contradiction between the finite local constraints is **not** evidence for quantum contextuality or metaphysical impossibility. No natural-language parsing, perceptual geometry, learned layout, or real-world sensor execution is present. Metatron/Megatron/Flower-of-Life names are motivating research metaphors, never evidence of causation or mathematical novelty.

### The next serious falsifier

A preregistered, independently scored human/model benchmark should compare NONE, fixed hex, fixed radial, typed multi-view and multi-view + proposed sensor against equally provisioned nongeometric CSP/active-learning systems. Count unjustified assertion promotions, scope leaks, correct abstentions and actual decision improvement. If visual geometry brings no measurable benefit, default to **NONE**. Freeze problem sets before optimizing any router.

**Research rule:** the new lens may reveal a question. Only additional attributable evidence can support a new answer. `PENCIL != PEN != external authority`.
