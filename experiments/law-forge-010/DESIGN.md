# LAW-FORGE-010 — THE BLIND FALSIFIER
## After an explanation survives, deliberately search for evidence that might destroy it

**User-approved next vertical.** Stacked research-only draft on LAW-FORGE-009 PR #76. The strongest new ingredient is not a new LLM or privileged ontology: it is a **separately budgeted falsification protocol** after identification, designed so a source-owned answer can reveal that *none* of the previously available 650 hypotheses explain all recorded observations.

The previous experiment demonstrated two things:
1. Its portable Shannon-entropy cartridge can select informative experiments while multiple rules disagree, and it tied a strong classical Gini/disagreement baseline.
2. Its `gap.py` can provide a mathematically verifiable contradiction certificate relative to the 650-rule language, **but normal active inquiry produced zero such certificates**. Once there was one surviving rule, the question selector generally stopped.

010 tests that precise defect **without editing the old source tests or reinterpreting the old result**.

## Frozen source and audit protocol

The experiment reuses **the exact LAW-FORGE-009 independent Stranger simulator** with ten researcher-authored rule families and twelve binary channels. The input domain has 4,096 possibilities. The source itself offers four initial observations, 128 authorized synthetic membership query cards, **192 disjoint independent-review inputs**, and **256 disjoint test inputs**. Review/test labels never reach the learner.

Every audit policy receives the same:
- **Learning phase:** up to 12 cost units of original 009 Shannon active learning, preserving exact witnessed lookup and version-space elimination. Learning stops at one surviving program or when the limited budget/catalog no longer permits a discriminating question.
- **Audit phase:** up to 12 **additional and separately accounted** cost units. An audit may begin *only when exactly one of the 650 frozen rules remains*; it may not declare the rule true. If no rule fits, 009's ordinary relative-to-grammar contradiction detector already applies; if multiple rules remain, the blind falsification phase is withheld.
- **Combined expense:** at most 24 synthetic source-cost units, with no more than 28 observations total (four initial + at most 24 one-unit questions). Every question is taken from an unchanged original 009 source-owned catalog; only the owner executes it.
- **Review:** recompute the 650-rule version space on all source training evidence, and invoke inherited independent review. If *all* rules are contradicted, emit a verifiable relative grammar-gap core and HOLD. This is **not proof that the world is illogical, nor permission to invent a new adapter**.

Unlike the separate earlier 009 study, this tests whether a retained explanation can be proactively challenged rather than merely verified on an external review partition.

## Match against strong classical rivals

All algorithms are classical, bounded, inspectable and source-separated from hidden evaluator labels.

| Policy | Post-identification audit choice |
| --- | --- |
| `mutant_challenge` | Freeze the surviving rule; compose bounded counterfactual mutants `rule XOR (AND of 1, 2 or 3 source bits)`. Retain only mutants matching *all witnessed observations*. Prefer source queries with the most remaining mutant disagreements, divided by declared cost; if no valid mutant remains, fall back to classical diversity. |
| `classical_diversity` | Maximize minimum Hamming distance from witnessed inputs per source cost. Strong space-filling audit baseline. |
| `classical_fixed` | First available authorized source card. |
| `classical_random` | Reproducible SHA-256-seeded pseudo-random score based only on current evidence and catalog, with cost penalty. |
| `no_audit` | Original entropy identification but *no* post-identification questions. Demonstrates incremental audit benefit, without pretending equal expense. |

The classical mutant set contains 12 single-bit, 66 two-bit and 220 three-bit XOR-of-conjunction modifications (**298 bounded alternatives**). This is a **predeclared critic language**, not self-generated novel logic. Mutation candidates are never silently added to the trusted 650-rule prediction model. Their purpose is only to select a falsifying **question** for the original identified champion.

The strongest performing matched classical audit baseline, selected from diversity/fixed/random *on development only*, sets the promotion hurdle. The mutant chooser must find **at least two more witnessed grammar contradictions**, cost no more and incur no extra independently approved test errors, otherwise the frozen decision is `NO_METHOD_PROMOTION`. Even passing would only `PROPOSE_FOR_HUMAN_REVIEW_ONLY`—no self-admission, merge, deployment or source privilege.

## What counts as a real finding?

The instrument is successful at **falsification** if, after finding exactly one candidate in the original 650-rule grammar, a newly executed owner-approved source question contradicts that candidate, causing **zero** rules to remain consistent with all training observations. The inherited `gap.py` reduces the witnessed evidence to an irreducible contradictory subset that independent local code checks.

The experiment explicitly distinguishes:

- **Unobserved setting:** old classical lookup has no fact. HOLD where models disagree.
- **One remaining model:** provisionally identifiable only within the declared grammar, *not proven*.
- **Training contradiction:** owner-supplied evidence falsifies the entire grammar. HOLD with a minimal counterexample core.
- **Independent review contradiction:** a separate source partition refutes a model even when learning/audit did not. HOLD, but **do not retroactively add review labels to training and pretend active discovery succeeded**.
- **Real-world validation:** not performed; this is source-separated synthetic scientific testing.

**Negative outcomes are valid:** If random/diverse audits expose more gaps, or the mutant program does not improve evidence collection enough to pay for itself, publish the negative finding unchanged.

## Portable auditable skill

The new strict JSON-stdio `desk.py` can:
- `open`: accept the actual LAW-FORGE-009 Shannon entropy reason cartridge and create a typed `motif.reason-cartridge.blind-falsifier.v1` audit ledger.
- `propose`: compute one bounded, source-catalog-derived **proposal-only** falsification question.
- `ingest`: accept a source-labeled synthetic response **only when** it corresponds to that precise, current proposal, within declared costs; return an immutable updated evidence ledger.
- `diagnose`: verify whether a **relative** grammar-gap certificate now exists.
- `predict`: reuse inherited exact-first, version-space-only prediction; HOLD when the source version changes or the evidence cannot justify a conclusion.

All serialized packets are data-only and must pass strict shape/revision/digest checks. They explicitly state `owner_must_execute=true`, `real_world_authority=false`, and never claim that a JSON source reference constitutes cryptographic witness authentication. The original owner and the research code are from the **same human team**. This is not a production network plugin, native GRAFT or ALEX approval, real source permission, or autonomous software extension.

## What this does not establish

Novel general intelligence, original mathematical reasoning, true counterfactual physics, external independently authored data, open-ended adapter invention, real operational costs, guaranteed falsification of all unknown mechanism families, calibrated confidence, physical risk minimization, automatic runtime evolution or permissions to access third-party records.

**Next hard falsifier:** Introduce an independently authored and signed external source contract, prohibit editing the critic library after opening its hidden evaluation, preserve a separate owner-provided cost model, and compare against source-aware Bayesian and stronger adaptive classical falsification baselines. Detecting falsification is not enough: it must be safe, efficient, and repeatable.
