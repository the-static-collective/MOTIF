# COGNITION-005 — Open-World Gap Hunt (frozen protocol, not a scored win)
**Status: EXTERNAL BENCHMARK PREPARATION.** Frozen before any MOTIF-vs-baseline execution. 2026-11-11.

## User question
Find independently documented problem classes on which a fixed closed-world planner reliably fails despite succeeding before the world changes. Test whether MOTIF can diagnose the hidden change, discover an affordance or missing action/model, repair its policy, and **recover faster or at lower resource cost than a strong adaptive classical or hybrid method**.

## Anti-strawman selection rule
Distinguish (A) *known-model classical search*, which is deliberately not designed to infer previously unknown operators, from (B) **classical adaptive model-learning and hybrid planning+RL**, which are legitimate strong comparators. A fixed PDDL model failing after novelty is a sensitivity check, **not proof MOTIF beats classical AI**. The strong baseline is eligible to update its model, probe the world and maintain source-verified memory. Freeze all policy descriptions, training and evaluation seeds, resource/action budgets and the task owner *before* any scored run. No revision using heldout results.

**External-first selection**: choose challenge regimes based on published results from researchers independent of MOTIF, not based on seeing MOTIF succeed. Verify original environment and license/usage restrictions. No corpus copied into MOTIF. Maintain exact upstream SHAs.

## Primary external trial: NovelGym (AAMAS 2024)
- Actual original source: `tufts-ai-robotics-group/NovelGym` SHA `0ad2cbb656177f76ff29f86793269b14879d9b89`; world implementation `tufts-ai-robotics-group/NovelGridWorldsV2` SHA `f5d06d4f5166ca985ca420c809129a79700d904e`. The NovelGym repo bundles a Metric-FF component distributed under GPLv2; clone only into an isolated test runner, never vendor/bundle it into this public MOTIF source.
- **Fire novelty** preselected: the crafting table becomes unusable until a newly introduced bucket is found and the fire extinguished; prior otherwise-successful plans no longer work. Its *published authors' evaluations* report 1.0 pre-novelty success and a maximum 1.0 novelty impact (post-injection immediate success fell to ~0 across tested hybrid/RL agents). Published adaptations took on the order of 127,200–372,960 training time steps, varying by agent. Those are **prior-paper results**, not ours and not exclusive to classical planners.
- Secondary independent novelties: `fence` (new prerequisite), `axe` (tool semantics change), `trader` (interaction distance changes), `chest` (beneficial new action). **Chest is necessary** to test beneficial novelty ignored by error-driven replanners. Distinguish harmful and beneficial changes. Novelty injection must stay intact; no preloading the novelty mechanics into MOTIF.
- Require unmodified upstream novelty world for scored runs, original upstream task-completion signal, and matched source access.
- First *development* milestone: prove the original source builds and one pre-novelty and one novelty episode run with signed owner observations, and reproduce a published baseline qualitatively. No advantage score until that succeeds.
- Frozen future comparison conditions: (1) original nonadaptive Metric-FF/PDDL; (2) original RapidLearn/hybrid model-adaptation baseline; (3) strong adaptive classical control combining novelty detection, active probing, local transition-model updates and replanning; (4) MOTIF with Understory historical provenance, Free Graph tentative explanations, reflection/contemplation and an explicit stop/verify policy. Each receives equivalent episode/environment budgets; nonadaptive-only comparisons must be labeled diagnostic.

## Independent secondary trials
- **AGNI**: `When Successful Strategies Fail: Adaptation to Environmental Novelty in Terminal Agents` (arXiv 2609.33870). Reported pass@1 drops on agent tasks as tool/resource/interface assumptions change; primarily evaluates *LLM-based agents*, not classical graph planners. External AGNI task adapters/permissions need discovery. No AGNI runtime, images, terminals or evaluation cases bundled yet. Appropriate for diagnosis vs mere anomaly detection.
- **Continual Learning Bench (CL-Bench)**: source `pgasawa/continual-learning-bench` SHA `5f8c50eb1e84b2eda2ef4faff757dfc812a0ea26`. Measures whether stateful agents actually improve across sequences; surprising negative prior-art result: simple in-context history can beat dedicated memory systems. Compare MOTIF's 4-mode system against stateful **and stateless** baselines with the same feedback, compute and memory budget. No scoring until native task runners are integrated.
- **NovPhy**: original `phy-q/NovPhy` SHA `0da1258c9c0ebb6b437d3f6291612b1032102678`, MIT license advertised. Independent physical-novelty problems with humans vs agents; validate engine and resource requirements before running, no claimed MOTIF results.
- **ARC-AGI-3** is *not* our headline gap. Modern systems already have near-perfect results on its semi-private set when reasoning state is preserved, and independent review has flagged benchmark elicitation/scoring problems. It remains useful for ablation, not as proof all current AI struggles.

## Hidden adaptation metrics, falsifiers and gates
- **Primary**: success and first return-to-success episode AFTER novelty on entirely unseen cases, under the actual external environment owner's outcome. Include the *time-to-adapt curve*, not only a terminal final victory; 10 attempts is a demonstration budget, not a scientifically validated task limit.
- **Secondary**: steps/CPU seconds/GHoT compute budget, number of source-truth probes, unauthorized action count, tested vs untested conjectures, bad surprises, catastrophic re-use of obsolete reflex, false novelty diagnoses, ignored beneficial novelties and evidence retention/recovery.
- **A legitimate win**: MOTIF exceeds **strong adaptive classical/hybrid** on external-heldout task outcomes or matching outcomes with independently measured lower total cost over multiple runs. Report confidence intervals, seed selection and compute hardware.
- **A negative result**: if both perform equally, no novelty claim; if both fail, document the unsolved model-learning problem; if MOTIF wins only over a static planner, state that this is expected in a world where the static planner's model was invalidated.
- No unrestricted action, live production changes, personal data, unsupported self-modification or continuous invisible application work. All external environments remain isolated and license-respecting.
