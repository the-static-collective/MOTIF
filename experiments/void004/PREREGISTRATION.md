# VOID-004 / Ten-try wave survival — frozen protocol, 2026-11-11

Objective: test whether a known opportunity to retry changes the value of gathering *source-verified* information before and across wave-survival attempts. This is an explicitly **author-built** deterministic Python fortress world, **not Crafter** and not an independent real-world benchmark. The code is seeded, reproducible and stdlib only; no remote services or paid models.

World: public 11×9 floorplan, four reachable relay terminals, twenty-four ordered attack waves (four gate directions). Every hidden lane is generated from a deterministic SHA-256 seed/wave digest inside a separate owner object; repeated attempts reset exactly the same wave series. Public relay signage specifies which wave numbers can be revealed by visiting it, but *never* their hidden gate directions. One prep relay visit per attempt, at most four orthogonal movement actions. A relay reading and a current-wave sonar **share the same single information battery**: scouting a relay (three wave directions) sacrifices the live sonar (one current wave) for that attempt. The choice creates a real present-versus-future information tradeoff. A wrongly defended wave ends the attempt. Each step gives a source-sealed outcome, including the true lane revealed by combat after a win or loss. Observations and learned wave directions survive resets, player status and sonar do not.

Success: defend all twenty-four waves consecutively. Agent is told it may make **up to fourteen attempts** and that success within **ten** is the nominal difficulty target, not a guaranteed outcome. A >10 or unfinished result is recorded, never censored. The first success attempt is primary; unsuccessful cases count as attempt 15 in a complementary restricted-mean measure, not a fabricated win.

Policies, identical source surface and resource limits:
1. Classical iterative (strong): exact one-attempt expected wave-survival calculation under uniform unknown direction and the shared sonar constraint, plus an explicit discounted next-attempt value-of-information term; persists all verified memory.
2. MOTIF iterative: actual MOTIF-003 `analyze_first_moves` (from canonical experiments/003) scores source-supplied possible *future information access*, with a horizon set by attempts remaining and an explicit replay dividend versus retaining current sonar; persists the same form of verified memory. Does not invent gate contents.
3. Classical immediate (ablation): keeps its sonar for the current attempt and avoids advance investment in relays; it still learns from observed wave failures.
4. Classical no cross-attempt memory (ablation): same classical iterative controller within each attempt, but starts over without observations after each defeat.

Single owner and game dynamics for all; source grants direction only on explicit sonar, relay visit, or observed defense. All controller comparisons receive the same public map, relay wave coverage, step budgets, and owner observational interface. Neither controller can read owner lane schedule. No reward based merely on map coverage. Movement costs counted; false claims detected. Main comparator uses fair same-information classical Bayes logic; not claimed globally optimal multi-episode POMDP.

Primary test: paired heldout seeds **81001 + 17*i, i=0..23** (24 cases) never previously used by this wave experiment. Development smoke seeds **40101, 40103, 40107, 40111**. These are engineer-chosen, not externally hidden. Freeze method and this list before running heldout. Do not tune and rescore them as fresh. Report success fraction by 10 and 14, mean/median first-success attempt, capped mean over all 24, stage of early death, source-verified wave intel count, unique relay visits, accumulated reconnaissance moves, number of wrong defenses, and paired policy differences. A classical win or tie must be reported. No inference about physical survival or a trained model.

Adversarial tests: hidden truth never in public view; forged seal rejected; no unvisited relay intel; sonar once/attempt; retry clears sonar and restarts wave 1; disabling memory causes repeated failures; no explanation based on guesses is admitted as observed truth; tests confirm native analysis actually invoked. Experimental scope limited to fixed deterministic authored wave schedule and map. Dynamic hazards, uncertain cues and independent world transfer are future work.

## Development-only design amendment, frozen BEFORE heldout scores

An initial four-seed development smoke with sixteen waves and independent relay/sonar energy produced exactly five successes for all persistent-memory methods (too easy and no meaningful tradeoff). Before inspecting any heldout seed, the designer increased the challenge to 24 waves and made relay reconnaissance and the one-use sonar consume the **same** information battery, enabling an explicit explore-now versus survive-now decision. The four development worlds yielded first successes at attempts 9/9/9/10 for both anticipatory approaches and 10/11/12/12 for the immediate ablation. Those development numbers are NOT independent confirmation and informed the finalized experiment. There is no tuning or re-selection after the 24 heldout cases are evaluated.
