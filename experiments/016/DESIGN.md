# MOTIF-016 — THE GARDENER'S GARDENER
## Can observed failures change the METHOD used to build question methods?

**Status:** executable, finite, fictional, source-pinned **meta-procedure** synthesis. Not AGI, unattended recursive code rewriting, actual OpenManus execution, independent real-world source verification, or an autonomous authority holder.

**Branch stack:** This work builds on **MOTIF-015 PR #18**, which builds on **MOTIF-014 PR #16**. Preserve those source and adoption boundaries.

### The failure that starts the research
MOTIF-015 creates two genuine generated decision procedures: one optimizing known synthetic *expected cost* and another optimizing *worst-case cost*. An unusual assumed prior causes the expected-cost procedure to fail when a later distribution differs. This is an error in the **method-selection objective**, not necessarily an erroneous Dogram calculation or a false National Treasure question.

MOTIF-016 treats the old procedure-selection grammar as a revisable object:

\`\`\`
ORIGINAL META-GRAMMAR
  CONST(expected) or CONST(worst)

AFTER AUDITED OPPOSITE FAILURE TYPES
  IF observed_a_count >= generated_threshold
     THEN expected/worst
     ELSE worst/expected
\`\`\`

The candidate threshold and branch arrangement are synthesized by **finite search over a developer-supplied meta-grammar**. Nothing rewrites source code; every new selection procedure remains a checksummed held cartridge.

### The actual original reasoning organs
The source-pinned MOTIF-014 original National Treasure Question Box and Dogram native probe instrument are executed by both inherited MOTIF-015 procedure generators. MOTIF-016 also invokes National Treasure's *original*, exact-pinned \`buildQuestionFrontier\` on the meta-failure record itself. The results remain speculative/unsupported synthetic questions. A source locator in a fixture is **not** an independently recovered real source, nor does a content hash authenticate the origin.

### The critical information separation
Each scenario has:
1. **Observable**: a simulated independent sample of 16 observations, summarized as the number corresponding to state \`a\`. The self-revising method sees this observable *only*.
2. **Evaluator-only true synthetic prior**: concealed from the method; used after the method proposes \`expected\` or \`robust\` to compute that selected procedure's expected cost.
3. **Post-episode audit**: only for training/validation scenarios, a synthetic receipt exposing the two cost outcomes. This constitutes the *failure record* used to amend the meta-method grammar.

The prototype generates training (36), validation (24) and frozen holdout (36) with different independent pseudorandom seeds and slightly different regime orderings. Training and validation are allowed to inform the proposed meta-rule and its acceptance gate; **heldout is never supplied to the generator**, only to the final evaluator.

### Real strong baselines and negative cases
- **Always expected / always robust**: both fixed compiler-objective strategies.
- **Classical Beta(1,1) posterior-predictive threshold**: separately written rule based on the *same* sample of 16; a strong statistical comparator, not a strawman.
- **Per-case privileged oracle**: the evaluator's unattainable lower bound, never passed to the proposed meta-method.
- **Hostile inverted sensor (flagged)**: when observation integrity is marked failed, the meta-rule must HOLD, not issue a fake better choice.
- **Unflagged inverted sensor**: adversarial out-of-family cases retain the familiar validation-shaped report while their values are inverted. This MUST remain a counterexample: the meta-gardener cannot detect the bad witness from the input alone and may perform worse than the constant robust method. No robustness claim.
- **Insufficient bidirectional failure evidence**: no conditional grammar extension.
- **Repeated episode identity / training-validation overlap**: HOLD.
- **Modified cartridge**: checksum validation refuses modified numbers, instructions, and automatic installation.

### What would count as a useful advance
A newly generated, conditional meta-program improves measured cost on the independently frozen holdout mixture relative to *both* fixed method-building criteria; if it does, that demonstrates **successful domain-specific meta-policy composition** in a tiny known finite synthetic setting. It does not establish an independent invention beyond the known decision-tree/threshold-learning family, or an improvement over classical posterior estimation. This is *not* recursive self-improvement of a general AI.

The new meta-program is versioned, held for human review, and can be re-applied to future simulated observations. No original Dogram, National Treasure, OpenManus, ELF, LOADOUT, GRAFT, JAR;VIS, or MOTIF main file is modified.

### Next hard frontier
Rather than presupposing the one-dimensional drift sample, test **which observation to acquire** under budget; noisy/missing/misleading sources, including the **unflagged inverted reporter** in this experiment; multiple unknown method families; distribution-free or minimax-regret compiler objectives; *negative transfer* when the meta-rule trained on one family is moved to another; and the reliability of the source proposing meta-grammar changes. Source-owned bounded OpenManus edits remain only a **prepared operator request** until an independently verified actual model run under authority limits exists.
