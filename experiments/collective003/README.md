# COLLECTIVE-003 — National Treasure: questions that preserve the unknown

**User-directed frontier experiment:** take genuinely existing weird National Treasure
questions and give MOTIF's proof-carrying investigation a stricter epistemic
adversary. This is a *research-only stacked draft* on COLLECTIVE-002 #235
(on #233, on THOUGHT-028 and earlier unmerged parents).

The original Question Box outputs a question, provenance/support class,
missing aperture, and other question doors. Its native receipt deliberately
has NO answer or conclusion field. Our wrapper preserves that distinction.

## What we actually tested

- The missing-source *fictional time artifact* must select the
  **source-object aperture first**. The National Treasure research note is
  recoverable, but it is NOT a source verifying that a nineteenth-century
  museum artifact ever existed. The output stays FAILED / UNSUPPORTED.
- The *Particular Treasure* conversation has a described formation history
  and original research note; its question can advance to **counterevidence**
  without retrojecting new meaning into prior turns.
- The *strange time* case maintains mathematical permission versus realized
  physics. Time-machine language does not become historical/physical fact.
- *NuMatherology* keeps mathematical threshold inquiry separate from
  an alleged universal occult numerical law.
- The **Cicada Overfit** case uses the original National Treasure co-013/014
  synthetic matched specimens. One has TWO fixture-witnessed ancestries;
  the other supports formal resemblance while refusing an unsupported
  transmission claim. Neither is evidence about actual Cicada 3301 authors.
- The **Same State, Different World** question inspires an additional
  **newly authored** finite mathematics laboratory (not a native NT source
  fixture). Three four-node graphs have the same coarse observation of
  4 vertices and 3 edges but different structures. Exhaustive candidate-feature
  search finds the least-cost set of separating measurements from FOUR
  HUMAN-DEFINED feature operations. A distinct adjacency-based enumerator
  cross-checks all four outputs. Not arbitrary question grammar invention.

## A real method mismatch surfaced by the native run

Four native case receipts initially choose chronology because it is the first
unfilled generic aperture. But for *Same State, Different World*, chronological
research is not the discriminator between two **mathematically defined**
possible worlds; likewise, for *NuMatherology*, a historical date does not
establish a cross-domain numerical mechanism.

MOTIF now records an **explicit typed task-relevance objection** to the
original selection and proposes the next formal question instead. It keeps
the ORIGINAL Question Box receipt byte-for-byte unchanged, so corrections do
not rewrite its source owner. This objection is **engineer-coded for two
named cases**; it is not an independently learned semantic insight. For the
graph case, the proposed measurement is then genuinely executed and
independently enumerated. For NuMatherology the specific formal system
remains undeclared, so the alternative is HOLD pending a falsifiable model.

The recoverable case source locators now point to immutable actual GitHub
research-note files. That recovers what National Treasure wrote, **not** an
external historical witness proving the mystery.

## The bridge into MOTIF

Each investigation produces a review-only typed question node:

- pin and source excerpt of the ORIGINAL research note;
- exact native Question Box receipt, its uncertainty and alternate doors;
- one proposed NEXT ACTION keyed to the returned missing aperture;
- original provenance/support labels and explicit non-claims;
- immutable digest and re-entry that replays original source and tool;
- no invented original museum evidence, no model-internal reasoning transcript.

Finite graph and Cicada specimens are separately typed proof/fixture
cards, *not answers to every possible question in the mystery*.

**We do not claim to have answered original metaphysical mysteries.**
This trial asks whether MOTIF can carry unanswered questions and
appropriate evidence beside calculable fragments without laundering one
into the other.

## Reproduce

Requires Python 3.11, Node.js 20+, Git, and checkouts pinned to the commits
above. GitHub Actions checks out the two National Treasure states independently
and verifies them before running:

    NT_CASE_ROOT=external/nt-cases NT_BOX_ROOT=external/nt-question-box \
      python -m unittest discover -s experiments/collective003 -p 'test_*.py' -v

    python experiments/collective003/national_treasure_frontier.py \
      --case-root external/nt-cases --box-root external/nt-question-box \
      > collective003-national-treasure-research.json

CI also executes the original source-owned Node tests:
node tools/question-box/test.mjs and
node --test cases/cicada-overfit/validate.test.mjs.

## Unsolved / next research pressure

- Source-owner notes are NOT independent historical provenance.
- No model inference or external original-source retrieval.
- Finite graph feature vocabulary and costs were authored for this test.
- No verified discovery of novel mathematics, physics, historical transmission,
  or independently improving collective intelligence.
- Git hashes demonstrate integrity, not authenticated human identity.
- Re-entry recomputes receipts; no measured end-to-end speedup.
- To genuinely advance: use independently authored primary-source objects
  or held-out questions, let MOTIF use source retrieval to complete missing
  provenance, pressure competing explanations with measured evidence,
  then carry BOTH negative and positive records into the next turn.
