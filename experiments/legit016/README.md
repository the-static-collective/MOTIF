# MOTIF LEGIT-016 — THE EMPIRICAL COMPOUNDING WITNESS

**Status: RESEARCH HOLD.** This experiment does not generate a new algorithm,
auto-merge code, or forecast accelerating intelligence.

## The question

LEGIT-015 mathematically demonstrated how improvements can compound by
raising useful work capacity, financing later improvements, and improving
the efficiency of the *improvement process itself*. But those results
used entirely hypothetical probabilities and multipliers.

**LEGIT-016 asks what actual executed MOTIF source, test data and
engineering costs currently demonstrate.** It does not fit a growth
curve to an insufficient record.

## Actual execution, not theoretical planning

The new instrumentation:

1. Reads the actual saved LEGIT-014 source, source-manifest and 80-graph
   performance trial. It checks matching SHA-256 and retains the prior
   HOLD_NO_RELIABLE_RUNTIME_IMPROVEMENT decision.
2. Reads the actual LEGIT-015 synthetic economics report and confirms it
   did not count the rejected 014 candidate as an empirical gain.
3. Loads *real Python source generated by LEGIT-012, LEGIT-013 and
   LEGIT-014* and checks each against previously committed source proofs.
4. Regenerates the frozen LEGIT-014 source through its own previous
   source-template generator, invoking the **real external Z3 verifier**.
5. Executes the three generated solvers and a separately implemented
   strong conventional cached DP on **24 newly seeded synthetic DAGs,
   comprising 28,560 graph states**. Every answer matches a separate
   exact-scanning mathematical oracle.
6. Measures actual wall-clock and process CPU times in nine rotating-order
   runs, index setup, Z3/source compile cost, and a separate small
   Python allocation sample. Records raw samples, not just medians.
7. Analyzes both the old and new research episodes, and refuses to
   invent a future success probability or compound growth rate.

This builds a functional **empirical evidence instrument** for
self-improvement claims. The measured programs are unchanged from
earlier generations.

## The existing real LEGIT-014 benchmark

The earlier trial had 10 proposed variants: nine mathematically sound
variants and one deliberately injected false hypothesis which Z3
refuted. They were **not 10 independent innovation episodes**.

The trial had 80 heldout-seed graphs with 117,243 reasoning states and
11 elapsed-time samples per arm:

| Actual implementation | Median batch runtime |
| --- | ---: |
| Earlier LEGIT-012 source | **141.903 ms** |
| LEGIT-013 source | 145.550 ms |
| Unpromoted LEGIT-014 source | **142.687 ms** |
| Strong conventional optimized DP | 161.333 ms |

The 014 source was 1.97% faster than 013, but **0.55% slower than
the earlier 012 source**. It was correctly held, not adopted.

The real 014 experiment also recorded **1,850.745 ms** of profiling
and **2,874.055 ms** of candidate proof/compilation. If all those
costs were charged to the selected improvement, and if its tiny
advantage over 013 persisted identically, a simple illustrative
break-even calculation requires **about 1,651 future 80-graph batch
executions**. Relative to the faster 012, there is no positive
observed break-even at all.

This amortization assumes stationary workload and execution speed.
It is not a forecast, an incremental deployment cost, or a measurement
of the entire human engineering budget. It excludes integration,
maintenance, rollback and context switching.

## New source-grounded LEGIT-016 measurement

The new 24-graph corpus has distinct predetermined seeds but uses the
same assistant-authored graph-generator family. It is *not* a
third-party independent challenge. Every one of 28,560 graph-state
answers matched the independent reference.

| Actual implementation | Median wall time (9 runs, new 24-graph batch) |
| --- | ---: |
| Earlier LEGIT-012 source | **43.469 ms** |
| LEGIT-013 source | 44.755 ms |
| Unpromoted LEGIT-014 source | **44.146 ms** |
| Strong conventional optimized DP | 50.572 ms |

LEGIT-014 is **1.56% slower** than LEGIT-012, 1.36% faster than
LEGIT-013, and 12.71% faster than this particular strong
conventional Python implementation. The direction of the negative
comparison against the best previous generation persisted.

These are exploratory readings on one CI runner. The new and old
corpora have different total graph-state counts and their raw
milliseconds must not be interpreted as the same amount of work.
The optimization families are conventional Boolean-set algorithms;
none of this proves superiority over classical mathematics.

The frozen measurement report also contains exact raw wall and
process CPU measurements, environment details, source SHA hashes,
setup time and allocation samples. Peak Python allocation tracing
has different measurement overhead from wall-clock timing and is not
a definitive memory comparison.

## Compounding cannot yet be inferred

To establish an empirical compounding effect we would need real
successive *adopted* improvements and evidence that earlier
improvements causally lowered the cost, raised the yield or unlocked
the discovery of later improvements.

Our evidence does not show that:

- LEGIT-014 remains HOLD instead of an admitted improvement;
- the heldout cases share a researcher and graph-generator family;
- repeated timings are measurements of one program, not independent
  successful inventions;
- the 9 sound source variations in 014 are a very narrow hand-defined
  language, not a random sample of improvements;
- independent task authors and authenticated external custody remain
  unverified; and
- full end-to-end returns are not demonstrated.

The executable decision is therefore:

**observed_compounding_rate = NOT_ESTIMABLE**

**promotion_decision = HOLD_NOT_ENOUGH_INDEPENDENT_EVIDENCE**

An artificial 100% improvement in the measured timing entries still
cannot bypass the missing independent-verification and provenance
requirements. Tests exercise that adversarial situation.

## Prospective experiment receipt contract

A new typed prospective record asks for a content hash of candidate
and reference, a preregistered protocol hash, workload family,
outcome, actual proof/review/rollback costs and raw timing samples.

The presence of a boolean claiming external attestation is not itself
authentication. No trusted third-party signature/custody checker is
available in this experiment: the contract HOLDs forged verified
attestations and marks ordinary submissions unverified for research.

No record can automatically calibrate future upgrade probabilities
or grant production change authority.

## Reproduce

Python 3.11 and pinned z3-solver 4.16.0.0:

    python -m unittest discover -s experiments/legit016 -p 'test_*.py' -v
    python experiments/legit016/benchmark.py --emit

The second command writes an actual new measurement packet to
/tmp/motif-legit016-empirical-witness.json, and the dedicated workflow
archives it. Raw timing samples legitimately differ between runners.

Files:
- evidence.py — prior measured episode and strict 014/015 source bridge.
- measurement.py — actual Z3-reproved generated code, new fixed-seed
  test corpus, raw CPU/wall time and traced allocations.
- decision.py — full-cost break-even, no-extrapolation and strict
  independent-evidence HOLD gate.
- benchmark.py — reproducible orchestrator.
- test_empirical.py — adversarial source, timing, false success and
  unauthenticated-custody tests.
- generated/empirical_witness_report.json — actual CI measurement,
  including the original real-world-research refusal.

## Limits and next serious frontier

The program and benchmark designs are researcher-authored. Z3 proves
the defined finite bitvector logic, not all future software behavior.
The two CI trials do not constitute independently blinded, replicated
scientific performance measurements. Neither is evidence of a
general-purpose exponential self-improvement curve.

The useful next move is to invite independent challenge authors,
collect authenticated source and benchmark receipts across multiple
machines, and observe actual costs and successes over successive
adopted changes. Only then should LEGIT-015's opportunity-cost planner
replace its hypothetical returns with defensible bounds.

**The milestone is not a claimed breakthrough in self-improvement
speed. It is an executable witness that can demand evidence before
declaring an improvement has compounded.**
