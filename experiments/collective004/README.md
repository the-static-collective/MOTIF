# COLLECTIVE-004 — The Question Grammar Breach

**Research-only DRAFT** stacked on COLLECTIVE-003 #239, COLLECTIVE-002 #235,
COLLECTIVE-001 #233, and THOUGHT-028. Nothing merged, published, or installed.

## User-approved scientific question

Can MOTIF detect that its current *question vocabulary* is not capable of
telling two compatible possible worlds apart, compose a new executable question
from typed lower-level primitives, actually ask an observation owner, and
preserve the new answer with reproducible proof?

Unlike simply adding another developer-written graph measurement to the menu,
this experiment explicitly constructs a previously absent measurement AST.

## Original historical-epistemic source

The question is attached to the **real** National Treasure "Same State,
Different World" case, passed through the **original** Question Box engine.
The case and the Question Box are checked out and Git-SHA pinned by inherited
COLLECTIVE-003. The case's source question is not converted into a claim about
real external worlds.

## Reproducible 6-vertex thought experiment

Two *developer-authored* connected trees have six vertices and five edges.

World A edges:
(0,1), (0,2), (0,3), (1,4), (2,5).

World B edges:
(0,1), (0,2), (0,3), (1,4), (4,5).

These are nonisomorphic: A has two length-two branches from the degree-three
hub; B has a three-edge branch and two length-one branches.

Every measurement available from the earlier COLLECTIVE-003 finite menu is
identical on both:

- number of vertices: 6
- edges: 5
- max degree: 3
- connected components: 1
- triangle count: 0
- degree multiset: [1,1,1,2,2,3]

Therefore **no function of those existing readings** can identify which
hypothesis is realized. That is a formal failure of this question vocabulary,
not a claim about general mathematical impossibility.

## The executable enlargement

Given *both possible models, but NOT the hidden source owner's realized choice*,
MOTIF enumerates previously absent ASTs by composing:

- existential quantification over graph edges;
- two generic bound endpoint variables;
- degree-equality primitive for each endpoint;
- degree constants drawn from the candidate graph inventory.

This yields six unordered endpoint degree-pair queries; they are enumerated and
independently executed using two distinct implementations. The only separator
among these existential queries is:

> Does an edge join two degree-two vertices?

A: NO.
B: YES.

The original previous question menu contained no such endpoint-degree
adjacency test. An actual synthetic source-owner method call supplies the
answer, identifies one of the two *declared* possible worlds, and creates a
proof-carrying packet with the original National Treasure source question,
old reading collision, complete candidate AST catalog, selected executable
question, source owner's observation receipt, surviving possible-world set,
revision, limitations and honest evidentiary status.

This is **bounded compositional program synthesis from a human-authored
primitive grammar**, not open-ended creativity, semantic understanding,
historically novel mathematics, or an LLM's original invention.

## Independently originated 1998 Graph Atlas pressure test

We went beyond the developer-written six-vertex toy graphs, using the
**original pinned LEGIT-022 carrier** for Read & Wilson's *An Atlas of Graphs*
(1998), distributed through NetworkX **3.4.2**. Source data checksum:
`73fc416df0164923607751cb759f4ae81deb5f6550bf25be59c86de3b747e41d`.
This Atlas and its 1,253 unlabeled graph types were authored independently
of MOTIF, although the experiment and challenge selection were authored here.

The original source-owned selection fixes **14 training / 28 held-out** pairs
*before* any new question output is examined. Pairs are selected by matching
degree multisets; all 28 heldout pairs are reported, including failures.

The question program grammar is **frozen from the six-node experiment**.
A previously unlisted edge/degree-pair existential question is synthesized
from the same typed primitives for each ambiguous pair, independently checked
through NetworkX and separate adjacency-matrix evaluation, and asked against
a *synthetic observation owner* holding one public Atlas graph.

### Executed, independently checkable heldout result

| 28 external Atlas comparison pairs | Number |
| --- | ---: |
| Already distinguishable by old question menu | **16** |
| **Indistinguishable by old menu** | **12** |
| Previously unresolved, separated by expanded grammar | **10** |
| Previously unresolved, STILL indistinguishable by expanded grammar | **2** |
| Identical-information exhaustive classical search | **Same 10** |

For the ten separable pairs, querying the simulated owner once for each
possible realized world (20 source-owner calls total) correctly identifies
20/20 cases. Source receipts are independently rechecked. For the two
unresolved pairs, MOTIF produces HOLD and makes **zero** fabricated
source-observation calls.

Train comparison: 14 total; three old-menu collisions, two recovered by
the new grammar and one remained HOLD.

**Interpretation:** On these 12 old-menu-collision cases, the expanded
question language extracts distinguishing information in 10 cases, whereas
no combination of the declared old readings can. This is a concrete,
bounded improvement in *expressive question capacity*, not a claim of
general or historically new mathematics. A strong classical enumerator
given exactly the same primitive grammar matches every successful result.

The Atlas test split is publicly reconstructible, not externally blinded.
The original 1998 graph data are independent-origin, but the source-owner
callbacks are still synthetic, the question-grammar design is human-authored,
and **the result does not establish live independent collective intelligence**.

## Strong controls and falsifiers

1. Disable new grammar: HOLD; no owner observations fabricated.
2. If old menu already distinguishes worlds: do not claim grammar failure.
3. A separate exhaustive classical algorithm independently evaluates the same
   primitive question grammar using an adjacency-matrix implementation.
   It selects the same question: **exact tie, no claimed superiority**.
4. Freeze the selected AST, then evaluate all 720 relabelings of *both* trees:
   1,440 independently checked results. This tests invariance, not independent
   real-world domains or novel graph isomorphism classes.
5. Transfer the frozen AST to two specifically authored 7-vertex extensions,
   which still collide on the old features: the new question still separates
   them. The extension is authored and not a blind independent dataset.
6. Re-enter the saved answer without a second investigative question, but
   re-check the current synthetic source owner and source evidence.
7. Reject a checksum-resealed false observation, swapped question text,
   unsupported grammar, missing proof or changed source revision.

The local synthetic world owner is a Python object, not a remote independent
scientist or an authenticated source. SHA-256 proves no external identity.
Full reruns mean no established wall-clock speedup.
