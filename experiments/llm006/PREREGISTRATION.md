## Frozen experiment
- Real pretrained public HuggingFaceTB/SmolLM2-135M-Instruct, pinned revision ee72e5415c002e8fc0566a191a07c0b2b708875a, frozen float32 CPU, transformers 4.49.0, torch 2.5.1; if weights unavailable, explicitly FAIL/HOLD. No simulated model substitute in a real model result.
- Four registered ODYSSEY sectors groups from LLM-005 are retained, but primary test = registered FIRST group (8001,8002,8003,8004), 48 consecutive hidden owner rule contexts, each 8 ordered checkpoints. 384 decisions, 96 evidence audits, 12 relays, 3 mandatory inter-world handoffs, at least 879 source-bound serial steps. Gate outcomes are exclusively independently returned by the existing LLM-003 Owner and its LLM-004 ReasonHypermap. The model NEVER receives truth index or future labels.
- For each unsolved stage query, require a real model forward pass and digit 0/1 logits. Obtain prompt from LLM-003's prior exact sample_prompt, with ONLY stage calibration and already observed unique verified source reports. No memory from other stage hidden rule; no pseudo-independent rumor source. The model can be confidently wrong. It cannot accept its own claim as a source or authorize a live action.
- Compare LLM_FLAT (only initial stage calibration, always) and LLM_MEMORY (same pretrained model, sees all independently verified prior stage observations, bounded seven observations) and LLM_VERIFICATION (LLM_MEMORY plus a paid independent precommit query only when expected simulated wrong+repair loss based on digit logit normalized confidence exceeds the known PROBE_COST=2). Fully identical fixed owner worlds, source access and classical LongChain mandatory gate verification. All model branches use actual forwards; when the calibration input is the target, reuse its independently verified source rather than claim a model inference. No training or manual truth-injected model choice.
- Strong controls from LLM-005: STATIC, CLASSICAL_BAYES, HYPERMAP_VOI (classical Bayes with same optional verification pricing). Do not claim model > classical unless shown; classical oracle may win easily. Model+verification is not the prior classical hypermap policy; do not conflate policies.
- Metrics (primary): completion vs failure of all 384 source-verified gates within existing hard per-subchain/global budgets, actual serial action count, model forwards, correctness of every first unverified PENCIL proposal, wrong commits, repairs, independent precommit probes, cost, first-failure cause. Comparative: LLM_MEMORY−LLM_FLAT prediction accuracy and cost, LLM_VERIFICATION−LLM_MEMORY utility, and strongest classical controls.
- Error dividend specifically: count model prediction wrong->right correction after evidence between successive model-generated PENCIL predictions for same target; also correct->wrong regressions. Each real model forward must be measured. A model prediction isn't an independent witness and correcting by using the owner report for the SAME task is not an improvement on an independent future task.
- Real memory claim requires model changed its future guesses from the earlier verified examples. Any posthoc targeted experiment must be labeled exploratory. Record exact source roots and prompt fingerprints per call, not hidden owner labels.
- Scientific limits: authored tiny eight-rule Boolean family, not independently owned real-world reasoning or general mathematical novelty. 135M model may perform badly and fail budget or learn little; classify failure, don't retune after inspecting outcomes. No production JAR;VIS deployment, no private user data, no provider keys, no external effects.
- Real-model CI is explicit, bounded (max 25 minutes; max <= 1200 model forwards; <= 220 input tokens per forward) and runs only public test fixtures. Publish independent execution receipts, even if failure (DO NOT mask failure). Mark first completed full marathon if any; do not claim 969 neural reasoning acts if only some actions involved the LLM.
- Before computing results, run 10+ source-boundary/unit falsifiers including prompts never reveal owner truth index, no future evidence, source-root dedup, repeated rumor ignored, all real policy choices require calls, fallback to exception on absent model (no random toy substitute), 384 exact gates cannot be shortcutted, and deterministic hash replay when fixed outputs supplied.
