# MOTIF-026 — Discovery of Discovery

**Implemented as a bounded experiment, not autonomous installation.**

The originating question ("Which live weather API could provide hourly forecasts?") cannot be answered by Eagle Eye's seven public metadata sources as a reliable live data interface. Actual original **ALEX-026** identifies the unsupported source family and, **only with explicit operator approval**, queries the public GitHub repository index for OpenAPI descriptions. It verifies public visibility, current commit and source tree, then fetches and checks exact immutable Git blobs. A candidate OpenAPI 3 **JSON** GET declaration is preserved with origin and review gates. YAML may be discovered but is *not* misleadingly claimed fully parsed.

The original **planZ-023 classical STRIPS/Dijkstra solver** receives this observed gap and finds a minimum-cost review plan. Original source-owned **GRAFT-026** then compiles real executable ES module code from an audited closed template and the verified proposal. It runs an **in-memory synthetic response fixture** and reports its data keys. It never fetches the candidate provider's server or installs the module.

After execution, MOTIF records the remaining source-authentication, service-host, license and authentication questions. The next question is generated but not automatically executed or handed production authority. The essential negative result is explicit: a verified Git blob containing a plausible OpenAPI document is **not proof that the advertised service is genuine, functional, independent or licensed for integration**.

All five imported ALEX and GRAFT modules are original Git blobs, checked before execution, and inherited 023 source pins still verify. CI includes source and authority refusal cases and direct executable fixture evaluation. No private material, HTTP requests to discovered servers, human contact, deployment, or automatic network permissions.

```sh
node --test experiments/026/test_discovery_machine.mjs
```

Additional live GitHub catalog discovery runs in source-owning ALEX-026 CI; search may legitimately yield no reviewable JSON OpenAPI candidate. Synthetic full-loop tests and genuine live discovery are separately described rather than conflated.
