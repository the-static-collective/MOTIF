# LLM-005 — ODYSSEY-240 / BORDERLINE UNREASONABLE REASON CHAIN
Preregistered **before implementation**, 2026-11-12. Stacked on unmerged LLM-004 PR #318; no other project's source state or private user artifacts imported.

## Purpose
Pressure the Reason Hypermap with a genuinely long **sequential critical path** requiring source-rooted decisions, recovery from wrong provisional answers, graph memory and evidence-gated milestones. Do not substitute a large number of independent trivia questions for a long causal chain.

## Frozen fictional world
- **12 sequential sectors × 8 dependent decisions = 96 decision gates**, each requiring a prior survey, then a bounded binary commitment, then source-verified acceptance or explicit repair after an incorrect proposed answer.
- **Each sector has its own hidden independently seeded rule** from the original eight-hypothesis Boolean family in LLM-003. It changes across sectors (concept drift). All 8 input patterns occur exactly once per sector, in a deterministic permuted order. One initial calibration is given once per sector as an independently rooted synthetic owner report; no additional truth leaks through surveys or candidate information.
- **12 intermediate audits, 12 terminal audits, 3 bridge-relays** add 27 non-answer milestones. Minimum successful action chain: **96 surveys + 96 accepted submissions + 24 audits + 3 relays = 219 actions**. Every successor is blocked until its predecessor is accepted; each terminal audit must be completed to advance. A wrong submission forces a separate repair step and retry.
- Global budget **350 attempted actions** and **400 synthetic cost units**, unless a predeclared policy stops rationally. The workload has at least 219 serial required steps even if every prediction is correct; a mistaken action incurs extra probe, repair, retry or costs.
- Total source classes: independent canonical synthetic owner acceptance report, provisional PENCIL model guess, repeated-root non-independent stage rumor (may be inaccurate), stale source duplicate, and resource receipts. No real persons, engineering actions, or living systems.

## Exact scored comparisons
- STATIC: each task uses the same initial one-observation posterior and discards the other tasks' verified feedback (does not remember source corrections).
- BAYES: updates the within-sector 8-hypothesis posterior after every independently verified gate (simple strong classical baseline).
- MOTIF_HYPERMAP: same Bayes posterior as BAYES plus limited up-front verification when expected failure/repair cost exceeds the independent probe cost (the project's error-dividend optimization). It may be worse when verification is expensive; no performance guarantee.
- CONTRARIAN: deliberately reverses plausible provisional answers on uncertain tasks; an intentional false candidate cannot earn an intrinsic reward. All displayed wrongs remain fictional PENCIL proposals; no false message is sent to a person.
- No model training, no real pretrained inference in this phase. The successor can later bind LLM-003 pretrained model proposals. A graph engine alone does not establish language-model improvement.
- 64 held-out authored simulator seeds [8001..8064], plus 8 distinct development seeds [1201..1208], with fixed predeclared resource and mistake costs. Metrics: hard completion fraction; 219+ action count; wrong commits; source-verified counterexamples; correct-to-wrong regressions; independent actual owner-graded net learning gain > cost; queried observations; repair actions; trace event IDs; chain hash; per-sector source-root count; final posteriority and unresolved fog. Report averages and range, do NOT retune based on heldout outcome.

## Source and state gates
- Use existing source-owned `experiments/llm003/error_dividend.py` Owner and `experiments/llm004/hypermap.py` ReasonHypermap, rather than generating a second unsupported hypothesis set.
- Each of 12 sectors owns its own map, distinct local source lineage and rule. Cross-sector relay/sector audit remains local simulated procedure; none grants real authority or changes Free Graph or JAR;VIS.
- Initial observed calibration may answer its matching task without spending another independent query. A stale root, echoed rumor, or imagined result must never count as independent evidence. Correct guesses still need gate verification. A wrong guess cannot advance until repaired.
- Owner hidden program index must never appear in the public trace, HTML or portable Free Graph export. Report labels from authoritative synthetic owner are explicitly source-scoped, not real world truth.
- No automatic live actions, account calls, filesystem writes outside generated public fixture, project deployments or irreversible effects.

## Falsifiers
1. Minimum 219 sequential milestone actions; verify the **dependency chain** rather than only total task count. Every audit and bridge is necessary.
2. At least 30 unit tests including wrong-retry gating, stage-rule drift, missing survey, stale receipt, repeated-root rumor, independently sourced corrections, budget exhaustion, no-false-promotion, immutable earlier states, deterministic replay, distinct stage source roots, completeness, and classical baseline.
3. Every algorithm must receive the same starting fixture and owner gate rules. The verifier may see hidden truth; the policies may NOT.
4. Two independent identical runs must produce identical canonical state hashes; one wrong answer changes the reason-map witness, not an already-verified earlier event.
5. Long-chain viewer is static offline HTML with step slider, filtered evidence types and mode comparison. No source/excerpt leak.
6. Benchmarked results must honestly admit when strong classical Bayes or even the STATIC baseline wins; don't turn a stress test into proof of general intelligence. Model calls/graph-based learning not run unless explicitly implemented.

## Fail conditions
Unfinished chain reported as completed; an incorrect answer accepted without repair; repeated owner receipt counted twice; synthetic source misrepresented as production; source conflict concealed; claimed novel math without external verification; simulated tasks called "real-world engineering". Keep all findings source-scoped and public-only.
