# ODYSSEY MARATHON — additional length stress (pre-code)
Date: 2026-11-12, frozen after the first successful 219-action single-run result and before marathon implementation. This is a separately labeled **post-hoc length escalation**, not retroactively the initial preregistration.

## Question
Can the same source-bound Reason Hypermap sustain a **single serial causally linked chain of at least 879 steps**, involving 4 ordered ODYSSEY-240 segments, **384 verified decisions**, **48 different sector-rule contexts**, **96 signed-in-fixture audit stages** (not cryptographically authenticated), 12 relays and 3 independently required inter-segment handoffs, without losing provenance or promoting a wrong guess?

## Frozen design
- Four 12-sector subchains each have a hard 350-action/400-cost sub-budget and must complete 96 ordered gates; a post-segment handoff is required before starting the next.
- Each handoff includes the exact prior terminal chain digest, the next segment's registered seed, and the global prior-hash. No handoff is eligible from a failed or incomplete chain.
- A global monotonically linked event ledger includes every underlying subchain action and 3 handoffs; a global event's digest includes the previous digest, original child event hash, the source segment number and the child event index. One incorrect proposal cannot erase an earlier source certificate.
- Synthetic owner truth is inaccessible to the policy beyond source-owner verification, and absent from public output. No real gate source, physical action or pretrained language model. Global 1,350 action and 1,800 cost ceilings.
- Register four distinct synthetic scenario groups of four seed values each, starting [(8001,8002,8003,8004),(8005,8006,8007,8008),(8009,8010,8011,8012),(8013,8014,8015,8016)]; report policy comparison on all four, with **no claim of external statistical significance**. Strong classical, memoryless, value-of-verification and contrarian continue as preregistered.
- Primary result is number of all-384-decision completed marathons, secondary number of real serial actions (>=879), global chain hash integrity, independent source verification count, total cost, source errors with and without repair, useful cross-sector corrections and failure reason.
- Hard falsifiers: no subchain skipped, 4 * 219 + 3 >=879, 48 rule sources distinct within each chain where generation permits, no mixing source-root authorities from one segment to another, valid global hash ledger, replay deterministic, 3 real inter-segment handoff events, 384 only if complete, any incompleteness means entire marathon incomplete.

This is an algorithmic long-horizon integrity / cost study over authored Boolean worlds, not general-purpose reasoning evidence. Separately grade memory usefulness using independent owner and record negative outcomes.
