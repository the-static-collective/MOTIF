# MOTIF-027 — Capability Gardener

This experimental branch connects source-owned GRAFT-027 candidate generation to original MOTIF-026 public API research and native planZ feedback plans.

Three frontiers were tested:

1. **New executable adapter designs:** Several distinct numerical JSON-field extractors are generated from previously unknown example structures. Withheld labeled cases reject misleading alternatives that passed training. A contradictory withheld case produces a HOLD and a different next classical research plan. The grammar is finite; this is not general programming.
2. **Search beyond existing providers:** Original ALEX-026 can discover source-pinned public OpenAPI descriptions outside Eagle Eye's original seven search providers. Search remains constrained to public GitHub and does not browse arbitrary sites.
3. **Actual third-party live read:** Original GRAFT-027 performs a separately approved, one-request Open-Meteo public API pilot using fixed published Berlin example coordinates, no personal location or credentials. The real response is checked and its checksum preserved in GitHub Actions. This is not an automatic connection to the newly discovered provider.

Tests include no-search-without-consent, multiple newly compiled programs, ranking on independent test examples, changed source material, withheld-case contradictions, limited network scope, and no production authority.

Run the local test suite:

```sh
node --test experiments/027/test_gardener.mjs
```

The separate GitHub Actions live read step may access Open-Meteo's public endpoint; its service terms and attribution still apply.

No production installation, user-account connection, full internet crawler, independent human-source identity proof, or persistent autonomous operation is claimed.
