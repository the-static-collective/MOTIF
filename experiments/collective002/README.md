# COLLECTIVE-002 — Missing-Link Question Invention

**Status: stacked DRAFT on COLLECTIVE-001 #233, itself on unmerged THOUGHT-028.**
No deployment or installation.

## User-directed hypothesis

When two prior answers include their relevant context, evidence, source scope,
and independently re-checkable proof, can MOTIF determine which *relationship
between them* is still unobserved, synthesize the relevant next question,
actually ask a scoped source owner, and carry the new evidence with its answer?

This first laboratory isolates that interface without simulating genuine
individuals, claiming privacy boundaries, or treating an inference as a fact.

## Concrete source-backed experiment

- Source proof **A**: an actual COLLECTIVE-001 result on THOUGHT-028's
  cancel_or_add task, independently verified on all 64 finite 3-bit cases
  and a separate reviewed fixed-template runtime.
- Source proof **B**: an actual COLLECTIVE-001 result on a *different*
  THOUGHT-028 toggle_equipment task, requiring additional development
  questions and its own 64-case proof and runtime check.
- The proof nodes produce finite masks with actual members. A source-owned
  but initially **unknown** synthetic cross-match relation is defined over
  3x3 possible left/right members. The cross relation is not established by
  the two mathematical proofs.
- MOTIF derives all AND ONLY the relevant member-pair questions from the
  actual verified masks. It does not receive any answers while generating
  these candidate questions. It selects a question from the typed grammar
  and sends it to an independent *callback* for the synthetic relation
  owner, gathering actual answers (not invented model strings).
- The result is a new proof-carrying node preserving **both entire source
  proof packets**, every relevant typed question with the parental proof
  digests, public source-owner contract, actual source query receipts,
  source revision, decision scope, negative observations, and unresolved
  limitations.
- Re-entry validates both parent proofs through their source-owner finite
  oracles, regenerates all relevant questions, and rechecks each previous
  answer against the current synthetic relation owner without generating
  new investigative questions.
- Positive result: one actual observed source match is a finite witness.
  Negative result: only after all relevant possibilities were checked
  **and only inside an explicitly closed finite domain**.
  Budget exhaustion or an open domain is HOLD, not global absence.
- A revised source owner or changed prior proof invalidates cached results.

This is genuinely an active question sent to another observation source,
but that source is a developer-authored fixture. Python objects in one
process do not enforce agent isolation or human-source authentication.

### Question selection and strong controls

The question policy orders generated candidate pair questions by public
declared prior probability divided by cost. This is the classical optimal
sequential search order under independent Bernoulli evidence, **not a new
algorithm**. A wholly separate exact permutation enumeration checks
minimum expected cost for <=5 candidate questions, alongside a
same-information canonical candidate order baseline.

Public priors are hand-chosen for the synthetic demonstration and are
not real-world calibrated. Benchmark records exact observed query counts,
source query costs, verification activity, uncertainty, and errors;
no performance superiority over a strong classical method is expected.

## Reproduce

Run from repo root (Python 3.10+, standard library):

    python -m unittest discover -s experiments/collective002 -p 'test_*.py' -v
    python experiments/collective002/benchmark.py > collective002-research.json

The CI workflow runs the source parent experiments and publishes the
complete inspectable research packet.

## Epistemic boundaries

- No natural-language inference, genuine independent humans/agents,
  deployed consensus, cryptographic source authentication, permission
  transfer, novel mathematics, or physical-world truth.
- Two task keys represent distinct source-scoped proofs, **not evidence
  of independent people or independent authoring**.
- A checksum alone is not proof of a source or authorization.
- Full finite parent re-verification is still performed on re-entry,
  so zero repeated *discovery* is not a measured overall latency saving.
- Synthetic priors and identical game mechanics between train/test
  do not establish research-method generalization.
- Relevant evidence belongs in the output, with provenance and unresolved
  questions; internal private model chain-of-thought need not be preserved.

## Falsifier for COLLECTIVE-003

Put genuinely independently originated tasks and observations behind
separate external owner-controlled endpoints. Query only with explicit
permission, and implement real provenance and revocation. Compare against
the strongest classical solver that receives exactly the same evidence,
question budgets and oracle access. Test novel grammar discovery,
contradictions, uncertainty and semantic mismatch, not only a matched
3-bit synthetic graph. Retain useful negative findings rather than
promoting another unearned claim.
