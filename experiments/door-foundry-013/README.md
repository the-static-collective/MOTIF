# MOTIF-013 — THE MISSING WORLD

**What if every currently available explanation is wrong?**

This bounded experiment takes the original four PNG world hypotheses from MOTIF-009 (crate left/right × partial/full-height wall), preserves their source hashes and decision history, and presents a **new synthetic two-time-point PNG observation** that none of those models can represent.

A full-height wall initially has eight blue cells. In the second synthetic frame, two adjacent blue cells disappear while the red crate remains stationary. The original four-world family has only 4-blue and 8-blue barriers. The original GRAFT-030 visual transition modes cannot *remove blue obstacle cells*. Thus, the new six-blue-cell image and transition are **outside the old closed model**, not merely unlikely under the old prior. MOTIF refuses to renormalize probabilities across those four insufficient hypotheses.

This is a finite source-grammar impossibility certificate **not a universal impossibility claim**, a real image observation, or a test of subjective consciousness.

## Actual source-owned new capability

1. Original MOTIF-007/MOTIF-009 recreate **four actual binary PNG hypothesis worlds** with source-verified byte hashes. MOTIF-010–012 prior experiments, GRAFT-030, CANNON-095, CANNON-096 and CANNON-097 run unchanged in the hosted pipeline.
2. New `missing_world.py` computes an **out-of-support certificate** against the original four PNGs and fixed-obstacle grammar, preserving the original source and producing the new *synthetic* before/after PNG pair. It does **not** silently assign nonzero likelihood to an impossible existing model.
3. Independent source owner [GRAFT-031 PR #27](https://github.com/the-static-collective/GRAFT/pull/27) compiles three genuinely distinct, locally executable **environmental-event model candidates**: keep the scene unchanged, remove a two-cell aperture inferred from the paired images, or remove all blue cells. Source-owned training, selection and negative tests choose the **two-cell event model**.
4. MOTIF **recompiles and reruns original pinned GRAFT-031 source** from immutable commit `8a4e85e2de9bdfdf74cd5bebd95fbab7cf11ab36` and exact Git blob, verifies its source hash and actual executable result, and refuses unauthorized physical command strings.
5. The original GRAFT-030 **movement** source is then used to compare complete finite reachability in the **old** full-height world and the **new** world *conditioned on the synthetic external event*. With the old wall there is no crossing. After the simulated barrier state changes, the red crate has a possible hypothetical crossing.
6. The new model remains **HELD**. A conditional future plan is not permission to change the external environment, take physical action, contact people, deploy a service or merge source.

## Independent verification

[CANNON-098 draft PR #98](https://github.com/the-static-collective/CANNON/pull/98) independently reproduces the same source-owned MOTIF-013 and GRAFT-031 evidence from immutable commits, directly decodes the original and new binary PNGs, independently recompiles the new generated model, and calculates reachability with its own classical JavaScript grid BFS. Its **11 independent tests** and complete source-owner GitHub Actions workflow passed, yielding a separate unsigned `HOLD_NEW_MODEL_BOUNDED_NOT_OBSERVED_OR_ADMITTED` review.

The new MOTIF-013 workflow itself ran **12 new unit tests**, plus all previous source-owner checks. It saves the original PNG worlds, source-deficiency certificate, source-generated GRAFT code and receipt, new simulated PNGs, original and expanded reachability, and a human-readable held explanation in `MOTIF-013-MISSING-WORLD-SOURCE-GENERATED-HELD`.

## Rigorous limits

**The trigger is an authored synthetic observation.** We have not invented a general mechanism for discovering unknown entities, sensor types, world schemas, or arbitrary mathematics. GRAFT picks from a deliberately finite generator family using selected examples; an equal-information classical enumerator could do so too. The new opening is a **hypothetical environment change**, not a command or a measured event. The actual world could be absent from the **new** limited model family as well.

Nothing contacted a human, inspected private photographs, called an external service, installed an operator, controlled a gate, merged branches or changed production.

**TESTED ≠ SELECTED. SELECTED ≠ EXECUTED. VERIFIED SOURCE ≠ VERIFIED WORLD.**
