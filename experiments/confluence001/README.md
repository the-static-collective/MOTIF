# CONFLUENCE-001 — The Coherent Field (draft research slice)

**Status:** experimental, isolated from `main` until review. **What runs:** a
source-receipted, multi-hypothesis, short-horizon inquiry loop that calls the
*original* MOTIF-003 affordance code against a separate synthetic construction
world, previews a plan with a separate fixture oracle, and preserves revisions.
**What does not run:** real construction, Android, MCP, independent sensing,
LLM, third-party web lookup, human consent acquisition or autonomous action.

## Why this exists

The older MOTIF-003 source has real executable affordance-search functions.
The newer FIELD-008 (draft PR #267) demonstrates evidence-rooted BLANCH
hypotheses with selective retraction, but its graph-identification results do
not outperform strong classical inquiry. The COLLECTIVE proof packets, IMMUNE
source lineage, question foundry, method diagnostics, Crafter execution and
temporal/TranchNode work also exist on **different unmerged branches**. We do
not silently copy, imply runtime integration or auto-merge those branches.

This deliberately small integration seam attempts a stronger end-to-end
claim than a disconnected toy: **Can a bounded controller actually preserve
source claims, keep alternative worlds provisional, spend observations on an
action-relevant hinge, preview a safe-in-all-candidates plan through an older
native module, and reopen the inquiry after changing observations?**

## Executed boundary

1. A `SyntheticOwner` controls one hidden 2-bit world (panel length and mesh
   safety), plus a separate explicit permission observation. All four worlds
   are developer authored, not empirical yard measurements.
2. Every source read yields an immutable snapshot in an append-only local hash
   chain; source membership is checked against a separately held source
   history. Hashes are **not signatures** or independent witnesses.
3. The planner retains each possible world as **PENCIL**. It records a frozen,
   pre-answer query proposal with conditional plans before asking the source.
   No PENCIL claim may become INK.
4. A bounded value-of-resolution hinge considers **both** candidate sensors,
   with stated integer costs and deterministic one-step utility lookahead.
   This is classical version-space search, not a novel active learner.
5. A plan is previewed only if its prerequisites hold in **all** surviving
   candidates and a fresh, explicitly observed fixture permission is true.
6. `adapter003.py` loads `experiments/003/affordance.py` **directly from the
   repository checkout**, runs its real `analyze_first_moves`,
   `select_first_move`, and `actions` routines. A conventional breadth-first
   search separately checks a route to the synthetic coverage goal. A
   second owner-fixture simulation checks the outcome. Neither is physical
   testing, and the external outcome is not recorded as a physical INK fact.
7. Observations have **illustrative, per-field integer-tick review windows**.
   When they expire, previous INK remains historical; current candidate
   worlds reopen. Simulated permission revocation forces HOLD. Expiry does
   **not** mean a claim became false or that a change definitely occurred.
8. Output includes the question/observation/preview chain, surviving
   conditional worlds, freshness notices, source-root count and explicit
   limitations. The chain is verified on each final report.

## Scope, evidence and comparison

Run from repository root with **Python 3.10+ and stdlib only**:

```bash
python -m unittest discover -s experiments/confluence001 -p 'test_*.py' -v
python experiments/confluence001/benchmark.py
```

The four fully disclosed fixtures cover (panel reach 1/2) × (mesh
safe/unsafe). A successful *simulation* requires either a span-2 panel or
source-verified safe mesh; permission is independently checked. We count
source query costs (measure panel = 1; inspect mesh = 2). The included
`benchmark.py` exhaustively scores both deterministic first-question
strategies against all four worlds, a strong classical exact contingent
baseline for this tiny case. The complete-reading baseline measures both
attributes in every case, even if the first measurement settles the task.

A tie to an exact classical control is expected and **not proof of algorithmic
advantage**. Using MOTIF-003 to evaluate affordances is separate from choosing
the evidence hinge, and the current design has not tested causal contribution
from MOTIF-003 versus a matched route search alone. It is an integration smoke
and correctness test, not general intelligence, historical novelty, real
survival advice or independent recursive self-improvement.

### Full architecture target (not claimed implemented)

`INK` verified historical facts; `PENCIL` unsupported hypotheses;
`BLANCH` reversible assumption spans; `TIME` freshness and trajectories;
`RELATIONS` typed fields; `AFFORDANCES` future possible actions;
`AUTHORITY` permissions and consent; `WITNESS` scope-limited proofs;
`METHODS` review-gated executable cartridges.

One living field should expose all nine as **distinct views over one shared
receipt/identity model**, not erase their boundaries.

## Acceptance gates for further integration

- Reproduce local and CI tests, inspect emitted artifacts.
- Establish typed versioned packet compatibility with the real FIELD-008 and
  COLLECTIVE contracts **without trusting source hashes as identity proofs**.
- Run a more independent unfamiliar-world test with hidden mechanisms, third
  party-sourced observations, temporal shift, witness conflicts and an
  equivalent-information exact or competitive classical baseline.
- Compare full system, no-003 ablation, no-provenance ablation and no-temporal
  ablation at matched query/time/compute budgets.
- Prefer negative results to forced success. Never allow a plan preview,
  unreviewed branch, or simulation outcome to grant any physical authority.
- Keep deployments, MCP actions, public reads, TranchNode identities and user
  information outside this research environment until reviewed independently.

**Do not merge wholesale stacks or install remote action permissions from this PR.**
