# FIELD-011 — Proposed independent evaluation

Test image-to-editable-board systems on unfamiliar, independently annotated sketches and photo sets across repair, gardening, storage, routing and improvised assemblies. Compare: plain chat, FIELD-010 manually drafted board, FIELD-007 deterministic first draft, browser-based first draft, direct VLM and VLM+pixel-critic+editable board. Freeze the input set and matched budgets before experiments.

**Measure**: retained line/object semantics separately from pixel detection, false desired-route claims, source-coordinate leakage, physically misleading lengths, correct user corrections, seconds and taps to a useful board, clarification turns avoided, chosen next measurement value, change in action selection, and negative outcomes. Include blank/ruled pages, handwriting resembling dashes, changing camera depth, alternate scene perspectives, ambiguous personal intent, and source-file replacement.

Keep user images private and use permissioned, safely observable tasks. A proposal does not certify improvised dog fencing or load-bearing safety. Passing authored unit tests does not show a general visual reasoner is superior to human or classical baselines.
