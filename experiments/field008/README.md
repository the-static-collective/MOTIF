# MOTIF FIELD-008 — TWO EYES, ONE SOURCE

## Objective

FIELD-007 can detect candidate dashed ink in a human sketch, but it cannot read the surrounding words, understand the person's task, or relate uploaded photographs to a practical goal. FIELD-008 introduces an **optional, local-only open-weights VLM** that proposes semantic/visual claims; a separately implemented source-pixel critic challenges claimed dotted lines rather than treating the VLM's text as physical evidence. The architecture also makes a concrete, cropped visual follow-up question when a proposed dashed segment lacks ink support.

**This is not a successful end-to-end real Qwen experiment.** No runnable VLM checkpoint is installed in the present runner and no original images have been sent to an external service. Local offline code/tests and CV-only private trial were executed. Local Qwen3-VL adapter was tested with mock responses. The code does not solve the entire fence route and does not certify actual construction or safety.

## Pipeline

1. Photograph and paper sketch remain private, with a unique source ID and immutable original file.
2. OpenCV FIELD-007 detects short source-image ink groups. `local_vlm.py` (explicit opt-in) calls a Qwen3-VL-compatible **Ollama server on localhost only** with structured instructions to identify text, objects, and dotted/solid mark candidates. No remote URL is permitted.
3. `critic.py` checks geometry, identities, repeated source-detected ink and unsupported imaginary marks, generating a traceable verdict. A textual object label is never independently proven by a pixel stroke detector.
4. `reinspect.py` turns an unsupported line into a bounded image crop for another look. `loop.py` permits one further local model inference on the crop. **Crop pixel coordinates cannot be interpreted as original-image or yard coordinates.** A second pass with the same model is correlated, not an independent witness.
5. All screenshots, reports, cropped images and user-owned photo inputs remain local. The *public* project receives only generic code, synthetic tests, documentation and author-generated synthetic image fixtures created at runtime.

## Scope of proof

- **33 local unit tests** of the contract, source-ink geometry checks, hallucinated marks, cropped follow-up, no silent data transfer, and source identity validation. Actual VLM responses were mocked.
- A **24-scene / 72 simulated-mark test** tests the critic against authored synthetic sketch patterns and deliberately false mock-model claims. The mock model is not an LLM; comparing to naive acceptance measures the effect of this rule against an intentionally trivial control, not superior visual intelligence.
- Private original sketch: FIELD-007 still detects **four tentative groups**. FIELD-008 can produce source overlay, second-look question and verification report when supplied a model packet; that input is not generated by a real VLM in this run.
- No cross-photo georegistration, scaling, absolute measurements, view orientation, material safety or autonomous novel construction.

## Reproduce on a laptop with an appropriate current local Ollama runtime

```sh
# Ollama >=0.12.7 and model already available (may require several GB of RAM)
ollama pull qwen3-vl:2b-instruct
python -m pip install -r experiments/field008/requirements.txt
cd experiments/field008
python -m unittest discover -v
python benchmark.py
python run.py --image /private/sketch.png --source-id sketch --out /private/results
# Explicit opt-in to a server running ONLY on localhost:
python run.py --image /private/sketch.png --source-id sketch --use-local-ollama --out /private/results
```

For environments without modern Ollama, a second local vision runtime can be added via a narrow reviewed adapter; don't silently fall back to an external service. Private source-image geometry is image-pixel-relative, not surveyed geography. A 200-lb advertised zip-tie capacity is not proof that a trampoline/chair/fence assembly is secure. Some improvised netting and wire may entangle or injure dogs.

## Next genuine evidence gate

Freeze third-party, human-labeled novel sketches/photos. On an available CPU/GPU that can run an open-weights vision model, run an actual local Qwen3-VL pass using identical privacy-consented inputs across VLM-only, CV-only, and CV+critic conditions. Inspect accuracy of handwritten current/dotted distinction, source-ink preservation, false junctions, object labels, structural hazard omissions, clarification-turn reduction, and time/cost. Negative controls should include similar-looking non-fence handwriting, rotated pages, identical chain-link patterns with different viewpoints, and false measurements. If the model calls fail or produce wrong interpretation, record failure and HOLD.
