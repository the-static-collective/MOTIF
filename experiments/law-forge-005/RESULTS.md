## The preregistered question

Treat “maybe trinary?” as a speculative proposal, not a scientific axiom or a default computational representation. Which **source-owned synthetic graph readout** is sufficient for a given binary outcome, at what declared symbolic capacity, versus equivalent binary encodings?

The experiment supplies exactly four edge bits per graph and ten handcrafted hidden outcome families. The learner receives an **identical common panel** of source-generated binary, ternary, pair, relational, and raw-graph readings. It fits a deterministic sensor-to-outcome model and ranks successful ones by a declared symbolic-capacity cost rule. No new sensor primitive was invented; the menu and evaluator were authored before trial.

The full-menu method selected a ternary program in 15 of 50 worlds (three specific graph-function families × five seeds). Those choices were *representationally sufficient*, but **not uniquely capable**: binary pair representations matched every eligible outcome.

Full-menu, binary-only and raw-four methods were tied on independent-review admission, withheld prediction coverage and errors. Their respective average source reads per eligible selected sensor were **3.125, 3.125 and 4.0** under the hand-authored toy sensor costs. This is a count of declared raw edge reads, *not a measured hardware, energy or network performance result*. Because the entire precomputed sensor panel was available to all methods, it cannot establish actual acquisition-cost savings.

In the 10 final-evaluation worlds that were HELD, independent review detected deliberate source-mechanism changes or unobserved context. No prediction was issued on the heldout data. Ternary-only also lacked a sufficient expressive view in several otherwise stationary worlds.

## The key falsifier: ternary disappears when binary storage is charged fairly

Under ideal abstract symbol capacity, a three-category state has `log2(3) ≈ 1.585` bits, versus two bits for a binary pair. That convention caused the full-menu learner to favor a ternary count in 15 positive final-evaluation worlds when source reads were tied.

When we replaced this assumption with **fixed-length binary encoding**, `ceil(log2(3)) = 2` bits, the full-menu learner proposed **zero** ternary sensors. It retained **exactly the same 40/50 independently eligible worlds, 1,280 withheld predictions and zero incorrect covered predictions**.

This is a direct measurement of how **the encoder/cost model—not some special metaphysical status of three—changed the preference**. No fundamental ternary ontology is demonstrated.

The frozen method decision was: **`NO_TERNARY_PRIVILEGE`**.

## Actual success and failure classes

- A single binary edge was adequate when the outcome depended on one edge.
- A 3-category neighbor count represented “exactly one of two edges” compactly, but a two-bit pair was equally predictive.
- A binary pair was *necessary under the restricted grammar* when the identity of the active edge mattered.
- A single binary relational reachability readout was sufficient when **any** two-hop path mattered.
- A 3-category path count represented exactly-one and both-path questions but offered no independent predictive ability beyond binary path pairs.
- The full four-bit binary baseline handled edge parity; ternary-only did not.
- Synthetic source shifts and hidden context were independently falsified and held.
- A proposed source sensor was re-reviewed on a new renamed synthetic destination; a different destination mechanism refused it.

## Source / security limitations

All phenomena here are authored finite graph mechanisms, not independently discovered scientific laws. Withheld seeds generate the same underlying mechanism families, not new unknown domains. The evaluator provided every candidate sensor interpretation and all readings; the learner selected a representation but did not create new hardware or an executable adapter. Tokens and checksums identify synthetic fixture content and do not authenticate real witnesses.

Strict typed probe/source/cartridge schemas prevent this experimental code from authorizing network access, real actions, contact with people, or automatic method promotion. None of ALEX, GRAFT, Dogram, Plan Z, reLATTE or live third-party services were newly connected.

**Next decisive falsifier:** have an independent source owner present a previously undocumented graph arity or relation, prohibit our fixed sensor menu from knowing it in advance, and require MOTIF to propose a *bounded new source-owned sensor definition* with a typed contract. Evaluate blind against binary, ternary, arbitrary-n, and graph-native competitors, respecting actual acquisition and integration costs. A failure to propose a valid sensor should remain a negative result.
