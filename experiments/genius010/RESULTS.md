## An instructive test failure

The earliest unit-test iteration incorrectly asserted that **no individual null comparison** could ever pass a corrected significance threshold in one confounded synthetic case. That is statistically wrong: even correctly calibrated null tests can give rare false positives. GitHub Actions flagged the assertion.

We corrected the test to require the genuinely specified result: **not all three independently sourced null contrasts may support one complete joint bridge in that case**. A single noisy marginal comparison cannot be promoted into a three-thread explanation. This is a correction to the test's logic, not a change made to force the dataset's classification.

Separately, a contested two-bridge scenario now returns **HOLD_MULTIPLE_COMPETING_BRIDGES** and no invented 3-way callback, rather than arbitrarily choosing the most appealing explanation.

## What did the creative crossing contribute?

When exactly one candidate has a valid **synthetic conditional** three-thread intervention contrast, the integrated GENIUS-009 two-clock module makes a later analytical source whose readings attach to each prior independent account:

`glasshouse observation` ← `later joint interpretation` → `broadcast observation`

`parcel observation` ← `same later interpretation`

All three pre-existing statements remain unchanged; the later interpretation is marked `INTERPRETATION_NOT_TESTIMONY`. If two candidate explanations pass, if a third thread disagrees, or if the source roots are repeated, the software refuses to manufacture narrative convergence.

This supports a limited **anti-forced-coincidence interface**. It does **not** measure comedy quality, demonstrate a real causal unifier, or prove that Povenmire/Acaster-style craft transfers to science. It tests whether source protection and a classical significance gate can precede the creation of a narrative bridge.
