# LLM-004 REASON HYPERMAP — preregistration (frozen before code)
Date: 2026-11-12. Stacked on unmerged LLM-003 PR #316. The request is to create a working reason hypermap where useful errors are remembered with what they changed, not merely described.

## Ownership and provenance
- MOTIF owns local hypothesis testing, posterior and provisional decision-memory state. Free Graph (the-static-collective/free-graph main) owns a historical portable projection vocabulary only. Understory, MEMENTO, Free Graph and JAR;VIS are NOT silently merged, called, or given action authority.
- Read Free Graph README, grammar/relation-v0.md, docs/contract-v0.md, schema/free-graph-v0.schema.json. Preserve its five portable verbs (connects, descends-from, tests, bears-on, constitutes); no sixth verb. No owner-local relation or constitutes without named owning-world gate and real gate receipt.
- A hyperedge (many sources -> many consequences) is reified as an ordinary 'test' or 'artifact' node; portable links use legitimate from/to fields, qualifier and local_relation extensions. Multiple lenses map one stable source coordinate to topological, causal, epistemic, decision and narrative views but must not change object identity, source access, or authority.

## Primary hypotheses
H1: An event-sourced reason hypermap can capture claim -> prediction -> discriminating test -> independently sourced result -> counterexample (or support) -> revised competing hypotheses -> newly promising investigation, preserving every earlier state and the exact source root.
H2: The map should distinguish an informative wrong *provisional hypothesis* from a harmful wrong *answer*. An error dividend exists only if a real independent test actually improves the owner-evaluated future decision net of query costs. In zero-feedback, echoed feedback, and corrupted feedback conditions the map must refuse promotion or reveal loss.
H3: A different lens on the same immutable coordinate may alter traversal/display but never facts, ancestry, authority, permissions or source disclosure.

## Experiment design
- Inherit real Python owner simulator and hypothesis library from the SOURCE-OWNED experiments/llm003/error_dividend.py (not restated imagined clones). All data inventoried as PUBLIC_SYNTHETIC_FIXTURE, no real user data.
- Build a small self-contained event-sourced hypergraph of typed vertices and typed multi-terminal edges. Model predictions stay PENCIL and may be contradicted; a source-independent owner report yields TEST evidence (not gate, legal authority or real-world permission). Repeated roots stay a single witness. Rejected feedback yields HOLD, no posterior update. Owner's hidden truth never enters a normal graph packet; permitted only in a separate evaluation scorer.
- An error dividend is measured by change in *independent owner accuracy* before/after verification minus a fixed probe cost of .04. Store test results and exact numerical deltas separately from observed facts; never infer positive value merely from disagreement.
- Precommitted comparisons on 160 seeded author-owned heldout worlds, budgets 0..3, truthful, noise20, echoed owner, absent feedback, same hypotheses and starting facts: classical expected information gain, deliberate challenge and expected Bayes predictive decision improvement as independent heuristic. Report classical wins and all ties. The last strategy may not beat information gain.
- At least 20 offline tests with negative controls: duplicated roots, missing verification, contradiction, correct candidate with useful evidence, wrong candidate without useful evidence, noisy false report, immutable event snapshots, export projection does not promote, graph validation, hyperedge membership, lens invariance, source redaction, same-origin text echo, isolated fork, bounded graph size, exact imported Free Graph contract validation where possible.
- Export a real Free Graph v0 shaped read-only specimen with content-addressed source/node/link IDs, and run the project-owned Free Graph scripts/fg.py validate against a pinned public source version if CI can fetch it. Fallback: validate locally and state it is a partial match; don't claim owner integration from an API shape alone.
- Produce a self-contained static HTML representation for a synthetic example if feasible, with lenses selectable and details inspectable, never user-specific data.

## Falsifiers and limitations
- A wrong provisional hypothesis can be useful; wrong user-visible claims are always failures. The exact classical owner truth is expected to outperform some heuristics.
- If no independent receipt or no posterior change, any invented dividend must remain zero/negative. Proof of graph schema parity is not authorization.
- Hash is content address, not cryptographic identity, owner consent or real-world trust; hidden truth is accessible to the test harness, not model policies. Fictional owner labels are not user witnesses.
- Do not merge into production, external effects, live JAR;VIS or private MEMENTO. No claim of novel mathematics, general AI improvement or production reliability from synthetic data.
