# MOTIF-015 — THE INVENTED GRAFT
## Can a questioner produce a new inquiry procedure from smaller licensed reasoning parts?

**Status: executable, fully synthetic known-model experiment.** This is **NOT** an independently trained world model, real autonomous self-improvement, a live OpenManus worker, a self-editing production source tree, or evidence about human behavior.

**Stack:** MOTIF-015 is stacked on the draft **MOTIF-014 Organ Gardener** branch. Do not merge this branch straight into \`main\` without resolving that prerequisite first.

### The actual organ crossing
MOTIF-015 invokes the **original, exact-pinned National Treasure Question Box** through MOTIF-014. In a genuinely incomplete (synthetic) evidence record, its missing-source / chronology / falsifier aperture causes HOLD *before* a mathematical instrument is invoked. Once its declared toy source record is complete, MOTIF-015 invokes the **original, exact-pinned Dogram** partition-refinement implementation from MOTIF-014. Dogram determines which supplied probes distinguish a candidate pair; this is a finite information-order calculation, **not evidence of cause or truth**. Source hashes are checked before invocation.

The new MOTIF-015 layer synthesizes *procedure cartridges* from the finite typed grammar:

\`\`\`
STOP(known_target_label)
ASK(permitted_probe, map observed_output -> another_program)
\`\`\`

It **enumerates and composes** previously unnamed conditional arrangements of those primitives. It rejects probes that make no distinction in the reachable state subset, rejects missing authorization, and refuses a partial classifier that gets any declared modeled state wrong. A generated AST may stop early if one observation identifies the target label; another branch may ask a second question. These exact methods are **not hardcoded complete policies**. The grammar, probe menu, source labels and cost model **are** hand-supplied. No new graph primitive, tool, language token, or external permission is invented.

### Strong benchmark, including a negative result
The independent reference is **classical optimal decision-tree dynamic programming** with the same input model and exact objective, *not* a random or handicapped baseline. Under frozen known-model assumptions our enumeration should **tie**, not beat, the optimum. The interesting difference is from a *single-question* method or a fixed-order system: synthesizing a branching procedure gives a reusable and inspectable composite capability.

- **Early-stop family:** a cheap probe identifies one common state, saving further questions on that branch; the generator constructs a conditional method.
- **New XOR family:** no individually allowed probe classifies all outcomes, but a two-question procedure does. The strong classical baseline obtains the same cost.
- **Unseen prior shift:** the learned-for-prior expected-cost method becomes more expensive than a fresh optimum and a worst-case method. Record the regression; do not silently install the modified method.
- **Withheld permission:** the only complete two-question method would need a prohibited probe. The synthesizer issues HOLD instead of making one up.
- **Missing source:** the actual National Treasure engine refuses a premature discriminator before Dogram runs.

### A first *approach*-revision proposal
The inquiry-method **search objective** is itself explicit and versionable: expected cost under a declared prior versus worst-case cost. The report asks whether a worst-case search should replace expected-cost optimization when the prior may shift. It tests both methods from the same original model but **does not automatically choose or install** the revision, and makes no claim that worst-case optimization is superior in every environment.

This is a first *inspectable approach-change cartridge*, not recursive learning of the policy-search algorithm. Genuinely learned meta-revision requires repeated, independently observed shifts and held-out families that are not supplied to the search/selection process.
