# MOTIF MAP-004 — Ask Free Graph which investigation deserves to happen next

**Built on original source-owned code.** [Free Graph REASON-SPACE-002 PR #21](https://github.com/the-static-collective/free-graph/pull/21) supplies the general abstract selector; this MOTIF experiment consumes it through the original Free Graph repository, rather than copying/claiming its authority.

## What now works

The previous native ALEX/planZ/Dogram/GRAFT investigation is recovered from an exact original Git blob. The Free Graph owner-native program converts it to a valid v0 graph, applies graph-native `reason_pressure()`, reads original recorded probe-instrument metadata, then selects possible **future research proposals** according to a strictly human-defined local task cut.

It recognizes that **ALEX, Dogram, GRAFT and planZ have already been invoked** on that historical evidence. It does not treat another search on exactly the same frozen inputs as an independent observation.

Four actually executed research selection controls, with no external execution:
1. No new positive witness or new scope → **do not re-run**; no selected tool. Optional LSD ideation profile is explicitly human-only.
2. Operator declares a new bounded public source scope → **propose GRAFT**, but do not call it or use network access.
3. Operator declares an original positive rendered performance witness → **propose owner-native PlayDeck validation**, but source authenticity and owner permission remain unverified.
4. Operator declines further investigation → **nothing selected**.

Each output preserves the original Free Graph reason packet identity, the unresolved status, source-owner citations, conditions for lawful next steps, and hard refusals of external actions and canon promotion.

## LSD finding

Historical LSD material in [The Daily Slice](https://github.com/the-static-collective/the-daily-slice/blob/23c3d4bf7e4febb89919a3d54b6e8aaf3a764120/slices/2026/08/2026-08-24/reality-bakers.md) is valuable as a **reversible divergence/alternative-hypothesis profile**: widen a single framing, return to the task constraints, preserve a proposal/receipt, and refuse automatic promotion. This complements rather than replaces ALEX's evidence adjudication or Dogram's graph computation.

**Not found:** A repository exactly named `the-static-collective/LSD` was not available through the connected GitHub action (404). Existing context treats LSD as a historical skill/protocol, not necessarily a runnable peer repo. This experiment therefore marks it as `HUMAN_ONLY_IDEATION_NOT_EXECUTABLE`, not falsely integrated native code. An actual original LSD executable could be pinned and tested only after its true source and permission are established.

## Genuine execution receipts

- [Free Graph original selector CI](https://github.com/the-static-collective/free-graph/actions/runs/42127881159) passed **69** regression+adversarial tests and four source-backed control scenarios.
- [MOTIF actual source-owned integration CI](https://github.com/the-static-collective/MOTIF/actions/runs/42128478730) independently checked original Free Graph Git head and **seven source file blob SHAs**, plus the original MOTIF historical receipt; ran six negative source/permission tests; and invoked the original selector on all four cases. Original full JSONs are preserved as a GitHub Actions artifact.
- `source-lock.json` records immutable code/evidence identity. The standalone `ask_selector.py` does not call GRAFT, ALEX, PlayDeck, or LSD automatically, nor any network, nor mutate any repository or human data.

The selected state is a **proposal**. It is not evidence that a new donor/positive performance document has been acquired merely because the task-cut flags say so. There are no measured electrical Joules, no autonomous learned policy and no independent generalization to unseen complex projects yet.
